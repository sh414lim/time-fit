# Android 태블릿 설치 안내

## APK 다운로드

`build/app/outputs/flutter-apk/app-release.apk` 파일을 태블릿으로 전송하거나 브라우저에서 다운로드합니다.

## 설치

1. 태블릿에서 APK 파일을 엽니다.
2. 출처를 알 수 없는 앱 설치 권한을 허용합니다.
3. 설치를 누릅니다.
4. 앱 목록에서 `timefit_tablet`을 실행합니다.
5. 관리자 이메일·비밀번호를 입력해 사업장 태블릿을 연결합니다.

## 운영 권장 설정

- 태블릿을 가로 방향으로 고정
- 화면 자동 잠금 해제 또는 장시간 유지 설정
- 앱 설치 후 홈 화면에 바로가기 배치
- 운영용 태블릿에서는 다른 앱 사용을 제한하는 Android 화면 고정/키오스크 모드 사용

## 주의

- 현재 APK는 테스트용 빌드입니다.
- Google Play 배포용 서명 키와 스토어 등록은 별도 작업이 필요합니다.
- Supabase URL과 publishable/anon key가 포함된 환경으로 빌드해야 실제 연결됩니다.
