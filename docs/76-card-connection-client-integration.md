# 카드 자동 연결 클라이언트 연동 1차

## 이번 구현

지출·증빙 화면에서 카드 자동 연결 수명주기를 호출할 수 있는 인증 클라이언트 계층을 추가했다.

- 연결 목록 조회: `loadCardConnections`
- 카드사 연결 생성: `createCardConnection`
- 보유 카드 탐색: `discoverCardConnectionAssets`
- 수집 대상 카드 선택: `selectCardConnectionAssets`
- 최초 백필 및 재동기화: `syncCardConnection`

모든 호출은 현재 Supabase 세션의 Access Token을 사용하며 15초 안에 응답하지 않으면 사용자가 재시도할 수 있도록 실패로 전환한다. API 오류 메시지와 오류 코드는 화면 계층에서 상태별 안내에 사용할 수 있도록 보존한다.

## 다음 구현 단위

현재 화면의 정적 연결 안내를 다음 상태를 가진 연결 마법사로 교체한다.

1. 약관 동의 및 사업자 유형 선택
2. 카드사 인증 요청
3. 조회된 카드 복수 선택
4. 최근 90일 최초 수집
5. 성공 건수·중복 제외 건수 표시
6. 실패 단계별 재시도 및 CSV 대체 동선

운영 UI에서는 Hyphen 샌드박스가 준비될 때까지 Mock Provider임을 명확히 표시하며, 실서비스 카드 인증정보 입력창은 실제 중계사 인증 방식이 확정되기 전에 노출하지 않는다.
