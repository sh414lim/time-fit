# TimeFit 리뷰 수집 연동 정책

## 지원 경로

1. **공식 API/제휴 API**: 제공사가 서면 또는 개발자 포털에서 승인한 범위만 수집합니다.
2. **사업장 소유 데이터 CSV 업로드**: 관리자 계정에서 내려받은 리뷰 내보내기 파일을 TimeFit에 업로드합니다.
3. **수동 등록**: 고객 컴플레인·개선 제안은 TimeFit에서 직접 기록합니다.

## 채널별 판단

| 채널 | 현재 경로 | 운영 원칙 |
| --- | --- | --- |
| Google | Places API | 화면 표시·보관 정책·출처 표기를 준수합니다. 리뷰 크롤링/재호스팅은 하지 않습니다. |
| Naver | 제휴 API 또는 관리자 CSV | 공개 지도 페이지 자동 수집은 제외합니다. |
| Kakao | 제휴 API 또는 관리자 CSV | Local API는 장소 검색용이며, 리뷰 수집 API로 가정하지 않습니다. |
| Catchtable | 공식 제휴/관리자 CSV | 파트너 API 승인 후 어댑터를 추가합니다. |

## CSV 자동 매핑

지원 열 이름(한국어/영문): `작성자`, `author`, `평점`, `rating`, `리뷰`, `content`, `내용`, `작성일`, `date`, `채널`, `source`, `리뷰 ID`, `review_id`.

- 업로드 시 사업장·채널을 지정합니다.
- 파일에 채널 열이 있으면 해당 값을 우선합니다.
- ID가 없으면 작성자·내용·작성일·평점으로 중복 방지 키를 생성합니다.
- 원본 파일과 API Key/Secret은 TimeFit에 저장하지 않습니다.

## 공식 자료

- Google Places API는 Place Details에서 리뷰 필드를 제공하지만, 지도 콘텐츠의 스크래핑·장기 보관에는 정책 제약이 있습니다.
- Kakao Local API는 키워드/카테고리 장소 검색을 제공합니다.

운영 전 각 제공사의 최신 약관, 보관 기간, 표시·출처 표기 의무를 다시 검토합니다.
