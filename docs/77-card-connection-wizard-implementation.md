# 카드 자동 연결 마법사 구현 결과

## 완료 기능

- 사업장 소유자 권한 확인
- 법인·개인사업자 유형 선택
- 카드 사용내역 수집·이용 필수 동의
- 카드사 연결 생성 및 보유카드 조회
- 여러 카드 선택 및 자동수집 등록
- 최근 90일 승인·취소·매입 최초 백필
- 신규·중복 제외·거래 그룹 결과 표시
- 기존 연결 상태와 마지막 성공 시각 표시
- 단계별 오류 안내 및 보유카드 재조회
- 동기화 완료 후 카드·거래 목록 자동 새로고침
- 모바일 단일 열 레이아웃

## 안전장치

- 카드번호 전체, CVC, 비밀번호를 저장하지 않는다는 내용을 동의 단계에서 표시한다.
- Mock 환경에서는 실제 카드사에 연결되지 않는다는 안내를 화면에 명시한다.
- 사업장 소유자가 아닌 사용자는 연결 생성과 카드 선택을 진행할 수 없다.
- 동일 최초 백필 요청은 서버 멱등성 키로 중복 실행되지 않는다.

## 검증

- Node 회귀 테스트 7개 통과
- Vite 프로덕션 빌드 통과
- 실제 Hyphen 카드사 연동은 테스트베드 키와 상세 API 명세 확보 후 별도 검증이 필요하다.
