## 출시 차단 이슈

1. **P0 — 태블릿 출퇴근 저장 실패**
   - 재현: 올바른 PIN과 등록 직원 전화번호 끝 4자리 → 직원 확인 → 출근하기
   - 결과: 저장 실패 안내 표시
   - 필요 조치: `tablet-attendance` Edge Function 및 관련 Supabase RPC/권한/날짜 처리 로그를 확인하고, 성공 응답까지 E2E 재검증

2. **P0 — 태블릿 휴가 신청 저장 실패**
   - 재현: 올바른 PIN·전화번호 끝 8자리·미래 날짜·반차 선택 → 휴가 신청하기
   - 결과: 신청 정보 확인 안내 표시
   - 필요 조치: `tablet-leave-request` Edge Function, 휴가 유형 매핑, RLS/RPC 오류를 확인하고 관리자 승인까지 재검증

3. **P1 — 관리자 근태 표시와 실제 저장 상태 불일치 가능성**
   - 출퇴근 관리에는 근무 중이 보이지만 태블릿 확인은 출근으로 판단한다.
   - 필요 조치: 관리자 조회 쿼리와 태블릿 조회/기록 API가 동일한 날짜·사업장·직원 ID 기준을 쓰도록 통일
