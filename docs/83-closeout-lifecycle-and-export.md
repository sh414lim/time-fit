# 결산 확정·재오픈·보고서 출력 구현

## 결산 수명주기

- `draft`: 급여 초안 또는 증빙 검토가 미완료
- `ready`: 자료가 완료되어 소유자가 확정 가능
- `closed`: 소유자가 결산 확정
- `reopened`: 수정 사유를 기록하고 재오픈

결산 확정과 재오픈은 데이터베이스 함수에서 행 잠금 후 처리한다. 재오픈에는 5자 이상의 사유가 필수이며 상태 변경과 사유는 감사 로그에 기록된다.

## 출력 기능

- UTF-8 BOM CSV 다운로드
- A4 인쇄 및 브라우저 PDF 저장 화면
- 합계: 순매출·확정 지출·인건비·운영순익
- 상세: 일별 동일 지표
- 보고서 하단에 생성 시각과 인건비 산정 기준 표시

## 화면 기능

- 최근 결산 8개 이력
- 기간·결산 유형·버전·운영순익·상태 표시
- 준비 상태 결산 확정
- 확정 결산 재오픈
- 재오픈 사유 표시

결산 저장·확정·재오픈은 사업장 소유자에게만 노출되고 일반 관리자는 조회와 보고서 출력만 가능하다.
