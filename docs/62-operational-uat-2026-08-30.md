# TimeFit 운영 데이터 변경 UAT 기록 (2026-08-30)

## 실행 범위

테스트 사업장 관리자 세션 및 연결된 태블릿으로 실제 Supabase 운영 데이터를 변경하며 검증했다.

## 통과

| 흐름 | 실행 결과 |
| --- | --- |
| 연봉제 계약 | `테스트1`에 연봉 42,000,000원 계약을 저장했고, 급여 화면에서 월 환산 3,500,000원으로 재조회됐다. |
| 급여 초안 | 해당 사업장의 월 급여 초안을 실제 저장했고, 재접속 후 `초안 저장됨` 상태를 확인했다. |
| 태블릿 출퇴근 | `최병주`의 전화번호 뒷자리로 실제 출근과 퇴근을 각각 저장하고, 재조회 시 다음 동작이 출근으로 전환되는 것을 확인했다. |
| 태블릿 휴가 신청 | `최병주`가 2026-09-01 연차 1일을 실제 신청했다. |
| 관리자 휴가 승인 | 위 휴가 요청을 실제 승인했고, 대기 0건 및 승인 완료 내역으로 재조회됐다. |
| 직원 직접 등록 | `UAT 주방직원`을 주방 · UAT 조리 · 시급 12,345원으로 실제 생성했고, 직원 목록에서 카테고리와 급여 형태를 확인했다. |
| 직원 편집 카테고리 | 이미 주방으로 설정된 직원 편집 모달을 열었을 때 `미분류`가 아닌 `주방`이 선택된 상태로 표시되는 것을 확인했다. |

## 반영한 보완

- 관리자가 초대 권한을 가진 경우에도 **직원 직접 등록**을 할 수 있도록 직원 관리 헤더를 `직원 초대`와 `+ 직원 등록`으로 분리했다.
- 연봉제 계약 이력과 급여 초안의 월 환산 표기를 지원한다.
- 태블릿 휴가 날짜 입력 이벤트를 보강해 날짜 선택 후 신청 내용 확인 버튼이 활성화되도록 했다.

## 운영 설정 검증 상태

- 2026-09-13을 직접 등록 공휴일로 추가하는 화면 동작을 실행했다.
- 브라우저 자동화 세션은 설정 저장 직후 React 화면 핸들이 무효화되는 현상이 간헐적으로 있어, 동일 탭에서 보상 기준 저장 완료 알림까지는 자동 재현하지 못했다.
- 실제 운영에서는 공휴일·정기휴일 보상, 급여 반올림, 알림 채널을 저장한 뒤 새로 연 설정 화면에서 값이 유지되는지 한 번 확인해야 한다.

## 주의

위 UAT는 실제 데이터를 남긴다. 테스트 직원과 해당 출퇴근·휴가·급여 초안은 운영 전 필요 시 관리자 화면에서 정리한다.
