## 잔여 이슈

1. **P1 — 새로고침 후 JWT 콘솔 오류**
   - 관찰: `InvalidJWTToken: Invalid value for JWT claim "exp"`
   - 영향: 이번 재테스트의 데이터 조회는 성공했지만 세션 갱신/토큰 발급 설정을 점검해야 한다.

2. **P1 — 관리자 직원 상세·홈 요약 샘플 데이터**
   - 실제 CRUD 데이터와 일치하지 않는 지표가 남아 있어 출시 전 실제 집계로 교체가 필요하다.

3. **보류 — 직접 등록 직원 계정 연동 UI, 카카오 알림톡 실제 발송, QR 카메라 실기기, 급여 정책**

## 판정

태블릿 출퇴근·휴가 신청 API는 깨끗한 신규 데이터에서 정상 저장·관리자 조회까지 통과했다. 단, JWT 콘솔 오류와 관리자 샘플 데이터는 출시 전 보완 권장 항목이다.
