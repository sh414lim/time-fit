## 3. 출시 판정

### 조건부 출시 가능

출퇴근, 태블릿 연결, 휴가 신청·승인, 관리자 데이터 반영, 화면 전환 안정성은 MVP 운영 가능 수준으로 통과했다.

다만 아래 항목은 정식 급여 정산을 범위에 포함하기 전 보완이 필요하다.

1. 일급제 단가 입력 및 실제 근무일 수 기반 예상액 계산
2. 태블릿 휴가 신청 저장 전 직원·날짜·휴가 유형 재확인 모달
3. 별도 물리 태블릿 또는 별도 브라우저 프로필에서의 최종 교차 테스트
4. 공휴일·정기휴일·공휴일 근무 보상 정책의 실제 데이터 회귀 테스트

## 4. MVP 운영 권장 범위

- 포함: 직원 등록, 스케줄, 태블릿 출퇴근, 휴가 신청·승인, 연차 현황, 시급·월급 예상액, CSV 확인
- 제외: 일급 자동 정산, 세금·4대보험·퇴직금, 카카오 알림톡, 세무사 이메일 발송
