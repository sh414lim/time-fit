# 영수증 미제출 자동 알림 구현

## 동작

- 법인카드 승인 내역에 연결된 지출 원장이 없으면 기본 3일 뒤 첫 알림을 생성한다.
- 이후 기본 3일 간격으로 최대 3회까지 한 단계씩 알림을 생성한다.
- 카드 담당자가 있으면 해당 직원에게 귀속하고, 공용 카드는 관리자 예외 업무함에서 처리한다.
- 영수증이 카드 내역과 연결되면 이후 알림 대상에서 자동 제외된다.
- 거래·회차·채널 복합 유니크 키로 같은 알림의 중복 생성을 방지한다.
- 매일 10:30(KST)에 예약 워커가 실행된다.

## 운영 설정

조직별로 `receipt_reminder_enabled`, `receipt_reminder_first_after_days`,
`receipt_reminder_repeat_days`, `receipt_reminder_max_count`를 변경할 수 있다.
예약 호출에는 `EXPENSE_REMINDER_CRON_SECRET`을 우선 사용하고, 기존
`CRON_SECRET`도 호환한다.

현재 채널은 앱 내부 알림이다. 이메일·카카오 채널 값은 스키마에 준비돼 있지만,
실제 외부 발송은 별도 발송 공급자와 템플릿 승인이 연결된 뒤 활성화해야 한다.
