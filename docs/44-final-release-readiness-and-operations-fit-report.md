## 5. 실제 운영 적합도

### 관리자 웹: 조건부 운영 가능

직원 조회, 스케줄 확인, 출퇴근 확인, 휴가 신청 노출, 급여 예상 확인 등 MVP 운영의 핵심 조회 흐름은 적합하다. 다만 신규 직원 등록과 스케줄 CRUD는 실제 운영 데이터로 한 번 더 검증해야 한다.

### 웹 태블릿: 조건부 운영 가능

사업장 연결, 전화번호 기반 출퇴근, 휴가 신청, 관리자 반영까지 실제 데이터로 확인됐다. 태블릿을 고정 운영하기 전 화면 잠금 방지, 네트워크 복구, 실제 기기 터치 테스트가 필요하다.

### 네이티브 Android APK: 테스트 배포 가능, 운영 보류

APK 생성과 위젯 테스트는 통과했지만, 현재 네이티브 UI의 최종 저장 액션은 운영 RPC 연결을 마무리하고 실기기에서 검증해야 한다. 따라서 Android APK는 내부 테스트 배포 단계로 평가한다.

### iPad: 운영 보류

Xcode/CocoaPods 환경과 Apple 서명 설정이 남아 있어 iPad 운영 배포 적합 판정을 내릴 수 없다.

## 7. 최종 판정

### MVP 웹 운영

**조건부 적합**

관리자 웹과 웹 태블릿은 핵심 MVP 업무 흐름이 실제 데이터로 확인되어 제한적 운영이 가능하다.

### 네이티브 태블릿 운영

**내부 테스트 적합 / 외부 운영 보류**

Android APK는 설치 테스트용으로 배포할 수 있으나, 실기기와 최종 RPC 검증 전에는 매장 공식 운영에 사용하지 않는다.

### 전체 스토어·현장 출시

**최종 보완 후 승인**

웹 MVP는 운영 후보 상태이고, 네이티브 태블릿과 iPad는 실기기·빌드·서명 검증 완료 후 최종 출시한다.
