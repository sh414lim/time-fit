# TimeFit 최종 사용자 사용 시나리오

관리자 웹과 매장 태블릿을 함께 사용하는 실제 운영 기준 문서다. 대상은 소규모 매장·사업장의 관리자와 현장 직원이며, 계정 생성부터 일일 출퇴근·휴가 승인·마감 점검까지를 다룬다.

## 1. 사용자와 사용 환경

| 사용자 | 사용하는 화면 | 핵심 목적 |
| --- | --- | --- |
| 관리자 | 웹 관리자 (`https://timefit-omega.vercel.app`) | 사업장·직원·스케줄·휴가·출퇴근·운영 기준 관리 |
| 직원 | 매장 태블릿 (`/tablet`, Android APK 또는 웹) | 전화번호로 출퇴근하고 휴가 신청 |
| 직접 등록 직원 | 태블릿 우선 | 계정 없이 현장 출퇴근·휴가 신청 |
| 초대 직원 | 직원 웹/추후 앱 | 초대 수락 후 개인 일정과 휴가 내역 확인 |

## 2. 운영 시작: 관리자 사업장 설정

### 시나리오 A — 관리자 가입 후 첫 사업장 만들기

1. 관리자는 TimeFit 로그인 화면에서 **관리자 회원가입**을 선택한다.
2. 이름, 사업장 이름, 이메일, 비밀번호를 입력해 가입한다.
3. 이메일 인증 없이 관리자 계정과 사업장이 생성되고 관리자 홈으로 이동한다.
4. 관리자는 `운영 설정`에서 사업장 표시명, 주소, 기본 휴게시간, 근무 형태를 설정한다.
5. 필요하면 `연차·월차·휴일 계산`에서 연차 발생, 월차 조건, 정기 휴일, 공휴일, 공휴일 근무 보상 기준을 저장한다.

**완료 기준:** 새 사업장이 생성되고, 관리자 홈의 현재 사업장명이 설정값과 일치한다.

### 시나리오 B — 현장 태블릿 연결

1. 관리자는 `운영 설정 > 태블릿 출퇴근`에서 태블릿 연결을 시작한다.
2. 태블릿의 초기 화면에서 관리자 계정으로 로그인한다.
3. 해당 관리자 소속 사업장을 선택해 연결한다.
4. 태블릿은 연결 완료 후 직원용 출퇴근·휴가 신청 화면만 표시한다.
5. 관리자는 웹에서 태블릿 이름, 상태, 연결 시각을 확인한다.

**보안 기준:** 관리자 로그인 정보는 태블릿 연결 완료 후 보관하지 않으며, 연결 해제·폐기된 기기는 출퇴근 및 휴가 신청을 할 수 없다.

## 3. 직원 등록과 근무 준비

### 시나리오 C — 관리자가 직원을 직접 등록

1. 관리자는 `직원 관리 > 직원 등록하기`를 선택한다.
2. 이름, 전화번호, 부서/직책, 급여 형태, 시급 또는 월급, 입사일을 입력한다.
3. 저장 후 직원 목록 및 직원 상세 화면에서 등록 정보를 확인한다.
4. 관리자는 직원 상세에서 전화번호, 급여, 직책, 입사일을 수정하거나 연차를 수동 부여한다.

**완료 기준:** 직원은 동일한 `timefit_user_staff` 기준으로 등록되며, 태블릿 전화번호 인증에 즉시 사용 가능하다.

### 시나리오 D — 초대 직원과 직접 등록 직원 연동

1. 관리자는 직원에게 고유번호/초대 정보를 전달한다.
2. 직원은 회원가입 후 초대를 수락한다.
3. 기존에 직접 등록된 전화번호와 직원 계정이 일치하면 같은 직원 레코드에 연결된다.
4. 관리자는 한 직원의 현장 출퇴근, 웹 계정, 일정, 연차를 직원 상세 페이지에서 통합 확인한다.

**예외:** 전화번호가 다르면 관리자는 직원 상세에서 번호를 정정한 뒤 다시 연동한다.

### 시나리오 E — 여러 직원의 스케줄 일괄 등록

1. 관리자는 `스케줄 > 근무 추가`를 선택한다.
2. 직원 카드에서 한 명 이상, 달력에서 날짜를 한 개 이상 선택한다.
3. 근무 형태와 시작·종료 시간, 휴게시간을 입력한다.
4. 저장하면 선택한 직원×날짜 조합이 일괄 등록된다.
5. 관리자는 일간·주간·월간 보기에서 일정 수와 직원별 근무를 확인하고 필요 시 수정·삭제한다.

**완료 기준:** 월간 보기에서 해당 월 전체 날짜와 등록 일정 수가 표시된다.

## 4. 현장 태블릿: 출퇴근

### 시나리오 F — 직원 출근

1. 직원은 태블릿의 `출퇴근` 탭에서 전화번호 뒤 4자리를 누른다.
2. 숫자 키패드 모달에서 번호를 입력하고 `입력 완료`를 누른다.
3. 입력 값이 출퇴근 입력 영역에 반영된다.
4. `직원 확인`을 누르면 직원 이름과 현재 가능한 동작(출근 또는 퇴근)이 확인 모달에 표시된다.
5. 직원이 `출근 완료`를 누른다.
6. 성공 모달을 확인하면 입력값은 초기화되고 태블릿은 다음 직원을 받을 준비 상태가 된다.

**관리자 반영:** 웹 `출퇴근 관리`와 홈의 실시간 출퇴근에 직원명·출근 시각·근무 상태가 반영된다.

### 시나리오 G — 직원 퇴근

1. 근무 중인 직원은 동일한 번호 입력 절차를 진행한다.
2. 확인 모달에는 `퇴근` 동작과 출근 시각이 표시된다.
3. `퇴근 완료`를 누르면 출퇴근 기록의 퇴근 시각과 실제 근무 시간이 저장된다.

**예외 처리:**

- 등록되지 않은 번호: 직원 정보를 찾을 수 없다는 안내와 재입력 동선 제공
- 이미 출근한 직원이 출근 시도: 퇴근 가능 상태 안내
- 아직 출근하지 않은 직원이 퇴근 시도: 먼저 출근해야 함을 안내
- 태블릿 연결 만료: 관리자 연결 화면으로 이동

## 5. 현장 태블릿: 휴가 신청

### 시나리오 H — 직원 연차/반차 신청

1. 직원은 태블릿의 `휴가 신청` 탭을 선택한다.
2. 전화번호 뒤 8자리를 키패드로 입력한다. 출퇴근 입력값과 휴가 입력값은 서로 독립적이다.
3. `휴가 날짜`를 누르면 달력 모달이 열리고, 신청할 날짜를 선택한다.
4. `연차`, `오전 반차`, `오후 반차` 중 하나를 선택한다. 선택된 항목은 색·음영·입체감으로 명확히 구분된다.
5. `휴가 신청하기`를 누른다.
6. 직원명, 날짜, 휴가 종류, 차감 일수가 들어간 확인 모달에서 `신청 완료`를 누른다.
7. 성공 모달 확인 후 입력값과 날짜·종류가 초기화된다.

**관리자 반영:** 웹 `휴가·연차`에 승인 대기 요청이 생성되고 홈의 승인 필요 건수가 갱신된다.

**차감 기준:** 운영 설정의 정기휴일·공휴일 제외 규칙, 공휴일 근무 보상, 직원별 부여 연차를 기준으로 계산한다. 법적·노무 적용은 사업장 정책과 근로계약을 우선 검토한다.

## 6. 관리자 일일 운영

### 시나리오 I — 오전 오픈 점검

1. 관리자는 홈에서 오늘 출근, 현재 근무 중, 확인 필요, 이번 달 인건비를 확인한다.
2. `실시간 출퇴근 > 전체 보기`에서 출근·미출근·퇴근 완료 직원을 확인한다.
3. 미출근 직원이 있으면 해당 직원 행을 눌러 상세로 이동해 연락처와 당일 스케줄을 확인한다.
4. 일정 변경이 필요하면 `스케줄`에서 해당 일정만 수정·삭제하거나 추가한다.

### 시나리오 J — 휴가 승인 또는 반려

1. 관리자는 홈의 `승인할 일이 있어요` 또는 `휴가·연차`에서 대기 요청을 선택한다.
2. 직원, 신청일, 종류, 차감 일수, 사유, 잔여 연차를 확인한다.
3. `승인` 또는 `반려`를 선택한다.
4. 커스텀 완료 모달을 닫아도 현재 휴가 관리 화면을 유지한다.
5. 승인된 요청은 직원 휴가 내역, 일정 표시, 잔여 연차에 반영된다.

### 시나리오 K — 월말 점검

1. 관리자는 `급여 관리`에서 직원별 급여 유형, 등록 급여, 실제 근무시간 기반 예상값을 확인한다.
2. `직원 관리`에서 신규 입사·퇴사·급여 변경·연차 수동 부여를 정리한다.
3. `스케줄` 월간 보기에서 근무일·휴무·휴가를 검토한다.
4. CSV 기능이 제공되는 범위에서는 다운로드 파일의 직원·기간·금액을 확인한다.

### 시나리오 L — 급여 유형별 현재 예상 금액 확인

1. 관리자는 직원 등록 또는 직원 상세 수정에서 급여 형태를 **시급제**, **일급제**, **월급제** 중 하나로 선택하고 해당 단가를 등록한다.
2. 태블릿의 출근·퇴근 기록이 저장되면 직원별 실제 근무시간과 근무일 수가 누적된다.
3. 관리자는 `급여 관리`에서 직원별 예상 금액, 실제 근무시간, 급여 형태, 근태 확인 상태를 확인한다.
4. 직원 행을 누르면 직원 상세에서 등록 단가·이번 달 근무시간·출퇴근 이력을 함께 검토한다.
5. 관리자는 CSV를 내려받아 월말 정산 전 근태와 예상 급여를 확인한다.

#### 급여 산정 기준

| 급여 형태 | 관리자가 등록할 값 | MVP 예상 금액 기준 | 검토 항목 |
| --- | --- | --- | --- |
| 시급제 | 시급 | `시급 × 실제 퇴근 완료 근무시간` | 휴게시간, 연장·야간·휴일 가산 |
| 일급제 | 일급 | `일급 × 퇴근 완료 근무일 수` | 반일 근무, 결근·유급휴일, 일급 분할 규칙 |
| 월급제 | 월급 | 등록 월급 | 입·퇴사 월 일할, 무급 결근, 수당·공제 |

> **현재 MVP 구현 범위:** 월급제와 시급제의 실근무시간 기반 예상액은 관리자 급여 관리 화면에 표시된다. 일급제는 선택·저장은 가능하지만, `일급 × 퇴근 완료 근무일 수`의 전용 산정과 일급 단가 입력 필드는 출시 전 별도 구현·검증이 필요하다. 현재 일급제를 시급 계산으로 대체해 표시하면 안 된다.

> **정산 제외 항목:** 4대보험, 소득세·지방소득세, 주휴수당, 연장·야간·휴일 가산, 퇴직금, 최저임금·근로계약 판단은 현 MVP 예상액에 자동 반영하지 않는다. 실제 지급·세무 신고 전에는 노무·세무 기준을 별도로 확정한다.

## 7. 화면 전환과 데이터 유지 원칙

1. 관리자가 메뉴를 이동해도 현재 로그인 계정과 사업장이 같으면 직원·일정·휴가 데이터는 초기화하지 않는다.
2. 메뉴 복귀, 다른 Chrome 탭 사용 후 복귀, 토큰 갱신 중에는 마지막 정상 데이터를 유지한 채 필요한 경우에만 백그라운드 갱신한다.
3. 저장·수정·삭제 후에는 사용자를 홈으로 보내지 않고 현재 업무 화면을 유지하며 결과 모달을 표시한다.
4. 계정 또는 사업장이 실제로 변경되거나 로그아웃된 경우에만 이전 사업장 데이터를 즉시 제거한다.

## 8. 운영 전 최종 합격 기준

- 관리자 가입 및 사업장 생성이 완료된다.
- 직접 등록 직원과 초대 직원이 하나의 직원 정보로 관리된다.
- 웹에서 태블릿 연결 상태를 확인·해제할 수 있다.
- 태블릿 출근·퇴근 기록이 관리자 웹에 즉시 반영된다.
- 태블릿 휴가 신청이 관리자 승인 대기 목록에 생성되고 승인·반려 결과가 반영된다.
- 직원 상세에서 개인정보·전화번호·급여·입사일·연차 부여를 관리할 수 있다.
- 스케줄의 일간·주간·월간 보기 및 수정·삭제·일괄 등록이 동작한다.
- 시급·일급·월급별 단가와 산정 기준이 화면·CSV·운영 정책에서 일관되게 확인된다. 일급제 전용 산정이 배포되기 전에는 일급 직원을 정식 급여 정산 대상으로 사용하지 않는다.
- 5초 이상 화면 또는 외부 Chrome 탭에 머문 뒤 복귀해도 로딩 고정·0값 초기화·다른 사업장 데이터 노출이 없다.
- 오류는 일반 성공 문구가 아닌 원인에 맞는 커스텀 안내 모달로 표시된다.
