# 카드 자동수집 장애 복구 구현

## 이번 구현 범위

- 인증 만료·권한 오류: `reauth_required`로 전환하고 자동 재시도를 중단한다.
- 호출 제한: 4시간 뒤 재시도한다.
- 카드사 점검·503: 2시간 뒤 재시도한다.
- 네트워크 장애: 15분부터 지수 백오프하며 최대 6시간으로 제한한다.
- 잘못된 요청: 24시간 뒤 재시도한다.
- 기타 장애: 1시간부터 지수 백오프하며 최대 6시간으로 제한한다.

연결 화면에는 `재인증 필요` 상태, 오류 분류, 다음 자동 재시도 시각과 즉시 재동기화 동작을 표시한다. 인증 오류는 무한 재시도하지 않아 카드사 차단과 불필요한 API 비용을 예방한다.

## 검증

- 오류 문구별 분류 테스트
- 인증 오류의 자동 재시도 중단 테스트
- 네트워크 장애 3회차의 1시간 백오프 테스트
- 호출 제한의 4시간 백오프 테스트
- 전체 단위 테스트 및 프로덕션 빌드 통과

## 다음 개발

실제 하이픈 재인증 입력·갱신 API와 연결 이력 감사 로그를 구현한다. 현재 화면의 재인증 안내는 상태를 정확히 노출하지만 인증정보 갱신 자체는 후속 범위다.
