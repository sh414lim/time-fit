# 영수증·카드 거래 검토 기능 구현

## 구현된 관리자 작업

- 확인 필요 영수증 목록 조회
- OCR 원본 데이터와 카드 거래 후보 조회
- 상호·거래일·금액·사업자번호·분류·사유 수정
- 카드 거래 후보 확정
- 잘못된 후보 반려
- 확정된 카드 연결 해제
- 미확정 지출 제외

## 이중 합산 방지

카드 거래 그룹은 `expense_sources`의 조직·원천유형·원천 ID 고유 제약으로 하나의 지출에만 연결된다. 후보 확정은 데이터베이스 함수 안에서 다음 작업을 한 트랜잭션으로 처리한다.

1. 카드 거래 원천을 지출에 연결
2. 선택 후보를 확정
3. 같은 영수증의 다른 후보를 반려
4. 지출을 확정
5. 카드 거래를 대조 완료로 변경
6. 문서를 매칭 완료로 변경
7. 감사 로그 기록

이미 다른 지출에 연결된 카드 거래를 확정하면 `409 card_transaction_already_linked` 오류를 반환한다.

## 수정과 취소

- 잘못된 후보는 확정 전 반려할 수 있다.
- 확정 후에는 연결 해제를 먼저 수행해야 지출을 제외할 수 있다.
- 연결 해제 시 카드 거래는 다시 미검토 상태가 되고 영수증 지출은 `review_required`로 돌아간다.
- 모든 확정·반려·연결 해제 작업은 감사 로그에 남는다.

## 다음 단계

지출·증빙 화면에 확인 필요함을 추가해 원본 이미지, OCR 값, 카드 후보를 나란히 비교하고 위 작업을 실행할 수 있도록 연결한다.
