# TimeFit MVP 종합 테스트 실행 기록

실행 환경: [TimeFit 프로덕션](https://timefit-omega.vercel.app)  
실행일: 2026-08-14 (Asia/Seoul)  
대상 사업장: 레오핏테크  
실행 방식: 관리자 웹·태블릿 전용 화면의 실제 Supabase 연동 점검

## 결과 요약

| 구분 | 결과 | 비고 |
| --- | --- | --- |
| 관리자 로그인·사업장 로딩 | PASS | 레오핏테크 관리자와 직원 3명 데이터가 정상 표시됨 |
| 운영 설정·연차 정책 UI | PASS | 연차/월차/휴일 정책 전체 표시 및 저장 요청 확인 |
| 직원 상세 개인정보 수정 | PASS | 기존 값을 저장 후 앱 재로딩, 사업장 데이터 정상 복구 |
| 추가 연차 부여 | PASS | 0.5일 부여와 이력, 잔여 계산의 실제 DB 반영 확인 |
| 태블릿 출퇴근 화면 | PASS | PIN·전화번호 키패드 모달과 개인정보 초기 화면 확인 |
| 태블릿 휴가 신청 화면 | PASS | PIN/전화번호 끝 8자리, 미래 날짜, 연차·반차 선택 UI 확인 |
| 관리자 출퇴근·휴가 데이터 확인 | PASS | 기존 실제 출퇴근 완료 및 승인 휴가 데이터 표시 확인 |
| 브라우저 오류 로그 | PASS | 관리자·태블릿 화면에서 오류 로그 0건 |

## 상세 실행 기록

| 시나리오 | 실행 내용 | 결과 | 확인 결과 |
| --- | --- | --- | --- |
| A. 관리자 운영 준비 | 로그인 후 홈 데이터 및 운영 설정 진입 | PASS | 레오핏테크·관리자 정보, 직원 3명, 기존 근태·스케줄이 표시됨 |
| A. 연차 정책 | 연차 15일/12개월, 월차 1일/월, 최소 근무 1일, 휴일 제외 설정 확인 | PASS | 모든 입력·토글·정기휴일·공휴일 UI가 표시됨 |
| B. 태블릿 출퇴근 | 태블릿 URL 접속 후 PIN 입력 버튼 선택 | PASS | 0~9, 삭제, 입력 완료가 있는 자체 숫자 키패드 모달 표시. 기기 키보드 미사용 |
| C. 태블릿 휴가 | 휴가 신청 탭 진입 | PASS | PIN, 전화번호 뒤 8자리, 미래 날짜, 연차/오전 반차/오후 반차 선택 UI 표시 |
| D. 승인·잔여 연차 | 기존 승인 반차 데이터로 직원 상세 확인 | PASS | 승인 사용 0.5일과 연차 내역이 표시됨 |
| E. 개인정보 수정 | 임시현 직원 상세 → 정보 수정 → 기존값 저장 | PASS | 이름·전화번호·부서·직책·급여·입사일 폼 표시 및 저장 후 앱 정상 재로딩 |
| E. 추가 연차 부여 | 임시현에게 0.5일, 사유 `MVP 종합 테스트` 부여 | PASS | 발생 0.5일, 사용 0.5일, 추가 부여 이력 `+0.5일 · MVP 종합 테스트` 확인 |
| F. 관리자 데이터 | 홈과 직원 상세 재진입 | PASS | 출퇴근 완료·휴가 승인·추가 연차 이력이 동일 사업장 데이터로 조회됨 |

## 실제 생성·변경된 테스트 데이터

| 항목 | 대상 | 변경 내용 | 현재 상태 |
| --- | --- | --- | --- |
| 연차 추가 부여 | 임시현 | 0.5일 / 사유 `MVP 종합 테스트` | 실제 DB에 유지 |
| 개인정보 저장 | 임시현 | 기존값 그대로 저장하여 수정 RPC 검증 | 실제 DB에 유지, 값 변경 없음 |

## 출시 전 후속 확인 항목

| 우선순위 | 항목 | 이유 |
| --- | --- | --- |
| P1 | 태블릿에서 새 휴가 신청을 생성하고 관리자 승인/반려까지 재검증 | 이번 실행에서는 기존 승인 데이터 확인과 신청 UI 검증까지 수행. 운영 데이터 추가 생성을 최소화함. |
| P1 | 정기휴일/공휴일 날짜에 대한 실제 신청 차단과 다일 연차 차감값 검증 | 정책 UI와 DB 계산 함수는 배포됐으나, 별도 테스트 사업장에서 날짜별 실제 요청을 권장. |
| P1 | 개인정보 수정 직후 새 전화번호로 태블릿 인증 검증 | 개인정보 저장 RPC는 실행했으나 운영 전화번호를 변경하지 않기 위해 기존값으로 저장함. |
| P2 | 실제 태블릿 기기 해상도·네트워크 환경 점검 | 브라우저 기반 UI 점검 완료, 매장 실기기 확인 필요. |

## 결론

핵심 관리자·태블릿·연차 관리 흐름은 프로덕션과 Supabase 실제 데이터 기준으로 정상 동작했다. 내일 MVP 테스트에서는 위 P1 항목을 테스트 전용 직원 또는 별도 사업장에서 추가 실행한 뒤 출시 승인 여부를 최종 결정한다.
