# 직원 영수증 촬영·제출 구현

- 직원 메뉴에 `영수증`을 추가했다.
- 모바일 후면 카메라 촬영과 갤러리 이미지 선택을 지원한다.
- 직원은 지출 목적만 선택적으로 입력하며 상호·금액·날짜는 OCR/LLM이 추출한다.
- 제출 즉시 Google Vision 분석과 카드 승인내역 후보 대조를 실행한다.
- 최근 제출 건의 분석 대기, 관리자 확인, 카드 연결 상태를 표시한다.
- 직원에게 귀속된 미제출 알림을 노출하고 본인만 읽음 처리할 수 있다.
- 직원은 본인이 올린 원본과 문서만 조회·처리할 수 있고 관리자는 조직 전체를 관리한다.
- 제출 직원과 지출 원장을 연결하고, 카드·영수증 확정 시 남아 있는 미제출 알림을 자동 취소한다.

운영 적용에는 DB 마이그레이션 011·012, Google Vision/LLM 환경변수와 비공개
Storage 정책 적용이 필요하다.
