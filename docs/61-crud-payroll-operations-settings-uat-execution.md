## 발견 이슈

| 우선순위 | 항목 | 내용 |
| --- | --- | --- |
| P1 | 연봉제 계약 이력 | 직원 정보 수정 화면에는 연봉제가 있으나, 급여 관리의 `급여 계약 이력 추가` 선택지는 시급제·일급제·월급제만 노출됨. 연봉제 직원의 계약 이력 생성/변경을 지원하도록 보완 필요. |

## 제출 전까지 확인한 항목

- 직원/구분/근무 형태 추가·수정·삭제 버튼과 검증 문구
- 급여 초안 저장·계약 이력 저장 버튼
- 연차·월차·휴일·보상·급여 설정 저장 버튼
- 태블릿 출근/퇴근 및 휴가 신청 최종 확인 버튼

## 아직 실행하지 않은 실데이터 검증

운영 데이터가 변경되는 행위이므로 별도 테스트 전용 직원과 날짜를 지정한 뒤 실행한다.

1. 공휴일 직접 등록 → 저장 → 휴가 차감 제외/보상 적립 검증
2. 연차·월차 정책 변경 → 발생 이력/잔여일 검증
3. 30분 올림 기준 출퇴근 저장 → 시급 금액 검증
4. 급여 초안·계약 이력 저장 → CSV와 스냅샷 불변성 검증
5. 태블릿 출근·퇴근·휴가 신청 → 관리자 승인 → 잔여 연차·스케줄·급여 교차 검증
