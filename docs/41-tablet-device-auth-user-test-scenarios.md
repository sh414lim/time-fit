# 태블릿 관리자 로그인 기반 출퇴근 사용자 테스트 시나리오

> 대상 버전: 프로덕션 `https://timefit-omega.vercel.app`
>
> 목적: PIN 없는 관리자 사업장 연결, 직원 출퇴근·휴가 신청, 관리자 기기 해제 흐름을 검증한다.

## 테스트 역할 및 사전 조건

| 역할 | 준비 사항 |
| --- | --- |
| 관리자 | 사업장에 `manager` 역할로 가입된 계정 |
| 직원 | 해당 사업장에 등록된 전체 전화번호, 전화번호 뒷 4자리·8자리 |
| 태블릿 | 브라우저 데이터가 없는 기기 또는 시크릿 창 |
| 관리자 웹 | 태블릿 연결 상태를 조회·해제할 수 있는 로그인 세션 |

## 테스트 데이터

- 테스트 사업장: 운영 데이터와 분리된 테스트 사업장 권장.
- 관리자 계정: 실제 사업장 관리자 역할 계정.
- 테스트 직원 A: 출퇴근 미기록 상태, 전화번호 뒷 4자리·8자리 확인.
- 테스트 직원 B: 출근 기록만 있는 상태.
- 휴가 테스트 날짜: 오늘 이후이며 공휴일·정기휴일이 아닌 날짜 1일.
- 차단 테스트 날짜: 운영 설정에 등록된 공휴일 또는 정기휴일 1일.

---

## 1. 관리자 태블릿 연결

### T-01 신규 태블릿 초기 화면

1. 브라우저 데이터가 없는 태블릿에서 `/tablet` 접속.

**기대 결과**

- `관리자 로그인으로 연결` 화면이 표시된다.
- 사업장 UUID, URL 쿼리 파라미터, 태블릿 PIN 입력란이 보이지 않는다.
- “관리자 계정은 태블릿에 유지되지 않는다” 안내가 표시된다.

### T-02 관리자 로그인 및 사업장 연결

1. 기기 이름에 `QA 카운터 태블릿` 입력.
2. 관리자 이메일·비밀번호 입력.
3. `이 사업장 태블릿으로 연결` 선택.

**기대 결과**

- 해당 관리자 사업장으로만 기기가 연결된다.
- 성공 모달 후 출퇴근 화면으로 이동한다.
- 태블릿 상단에 사업장명·기기명이 표시된다.
- PIN 입력란 없이 전화번호 뒷 4자리 입력만 표시된다.

### T-03 직원 계정 연결 차단

1. 태블릿 연결 화면에서 직원 역할 계정으로 로그인 시도.

**기대 결과**

- 연결이 거부되고 “사업장 관리자 계정으로 로그인” 안내가 표시된다.
- 기기 토큰과 출퇴근 권한이 생성되지 않는다.

---

## 2. 직원 출퇴근

### T-04 정상 출근

1. 연결된 태블릿에서 직원 A 전화번호 뒷 4자리 입력.
2. 직원 이름 확인 모달에서 `출근하기` 선택.

**기대 결과**

- 직원 이름이 정확히 표시된다.
- 출근 기록이 1건 생성된다.
- 완료 후 전화번호 입력값과 확인 모달이 초기화된다.
- 관리자 웹 출퇴근 현황에 출근 시각·출처가 반영된다.

### T-05 정상 퇴근

1. 동일 직원 A의 전화번호 뒷 4자리 입력.
2. 이름 확인 모달에서 `퇴근하기` 선택.

**기대 결과**

- 같은 날짜의 출근 기록에 퇴근 시각이 추가된다.
- 중복된 별도 출퇴근 레코드가 생성되지 않는다.
- 관리자 웹에 퇴근 완료 상태가 반영된다.

### T-06 잘못된 전화번호

1. 해당 사업장에 없는 전화번호 뒷 4자리 입력.

**기대 결과**

- “등록된 전화번호 뒷자리를 찾지 못했어요” 오류를 표시한다.
- 다른 사업장 직원 이름·개인정보가 노출되지 않는다.
- 출퇴근 기록이 생성되지 않는다.

### T-07 중복 기록 차단

1. 이미 퇴근 완료된 직원 A로 다시 출퇴근 시도.

**기대 결과**

- 중복 출근 또는 퇴근 기록이 생성되지 않는다.
- 현재 상태에 맞는 오류 또는 다음 행동 안내를 표시한다.

---

## 3. 태블릿 휴가 신청

### T-08 정상 휴가 신청

1. 태블릿에서 `휴가 신청` 탭 선택.
2. 직원 A 전화번호 뒷 8자리 입력.
3. 미래의 평일 선택.
4. `연차` 선택 후 신청.

**기대 결과**

- PIN 입력 없이 신청이 완료된다.
- 휴가 요청이 `승인 대기` 상태로 생성된다.
- 관리자 웹 휴가 관리 목록에 직원·날짜·유형·일수가 표시된다.
- 알림 로그가 대기열 또는 비활성 상태로 생성된다.

### T-09 반차 신청

1. 직원 A로 미래 평일 선택.
2. `오전 반차`, `오후 반차`를 각각 신청.

**기대 결과**

- 각각 0.5일로 계산된다.
- 날짜·유형·직원이 정확히 저장된다.

### T-10 공휴일·정기휴일 휴가 차단

1. 운영 설정에 등록된 공휴일 또는 정기휴일 선택.
2. 연차 신청 시도.

**기대 결과**

- 신청이 차단된다.
- “정기휴일 또는 공휴일” 관련 안내가 표시된다.
- 휴가 요청과 알림 로그가 생성되지 않는다.

---

## 4. 관리자 기기 관리

### T-11 연결된 기기 조회

1. 관리자 웹 로그인.
2. `운영 설정 > 연결된 태블릿` 확인.

**기대 결과**

- 기기 이름, 마지막 사용 시각, 만료일이 표시된다.
- PIN 입력 항목은 표시되지 않는다.
- 태블릿 접속 주소는 `/tablet`로 표시된다.

### T-12 관리자 기기 연결 해제

1. `QA 카운터 태블릿`의 `연결 해제` 선택.
2. 확인 메시지 승인.
3. 해당 태블릿에서 출퇴근 또는 휴가 신청 시도.

**기대 결과**

- 관리자 화면에서 기기가 목록에서 사라지거나 비활성 상태로 표시된다.
- 태블릿은 즉시 관리자 연결 화면으로 돌아간다.
- 연결 해제 후 출퇴근·휴가 신청 기록이 생성되지 않는다.

### T-13 재연결

1. 연결 해제된 태블릿에서 관리자 계정으로 다시 연결.
2. 같은 기기 이름 사용.

**기대 결과**

- 새 기기 토큰이 발급된다.
- 이전 토큰은 계속 사용할 수 없다.
- 새 연결 후 직원 출퇴근을 정상 처리한다.

---

## 5. 보안 및 회귀 테스트

### T-14 관리자 화면 접근 차단

1. 연결된 태블릿에서 루트 URL 또는 관리자 URL로 이동 시도.

**기대 결과**

- 관리자 로그인 세션이 남아 있지 않아 관리자 데이터가 표시되지 않는다.
- 관리자 기능 접근에는 별도 로그인이 필요하다.

### T-15 기기 토큰 만료

1. 테스트 환경에서 기기 만료 시각을 과거로 변경.
2. 태블릿 새로고침 또는 출퇴근 시도.

**기대 결과**

- 태블릿 연결이 해제되고 관리자 연결 화면을 표시한다.
- 만료 토큰으로 데이터가 생성되지 않는다.

### T-16 기존 관리자 기능 회귀

1. 관리자 웹에서 직원 등록, 스케줄 등록·수정·삭제, 휴가 승인·반려를 실행.

**기대 결과**

- 기존 CRUD 기능이 정상 동작한다.
- 태블릿 연결 도입으로 직원·스케줄·휴가 데이터가 다른 사업장에 섞이지 않는다.
