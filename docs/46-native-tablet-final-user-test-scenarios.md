# TimeFit 네이티브 태블릿 최종 사용자 테스트 시나리오

## 목적

매장 태블릿에서 관리자 연결부터 직원 출퇴근·휴가 신청, 관리자 웹 반영까지 실제 운영 흐름을 검증한다.

## 공통 테스트 환경

- 태블릿: Android 10~13인치 가로 모드
- 앱: 최신 TimeFit Release APK
- 사업장: 레오핏테크
- 관리자: `ceo1@leofittech.com`
- 네트워크: 인터넷 연결 상태
- 테스트 직원: 태블릿 인증 가능한 전화번호가 등록된 직원

## 1. 앱 첫 실행 및 관리자 연결

1. APK를 설치하고 앱을 실행한다.
2. 좌측 브랜드 패널과 우측 관리자 연결 화면이 표시되는지 확인한다.
3. 관리자 이메일·비밀번호를 입력한다.
4. `사업장 태블릿으로 연결`을 누른다.
5. 연결 완료 알림을 확인한다.

### 기대 결과

- 로그인 중 버튼이 `연결 중…`으로 변경된다.
- 성공 시 관리자 세션은 태블릿에 유지되지 않는다.
- 사업장 전용 출퇴근 화면으로 이동한다.
- 실패 시 이메일·비밀번호 또는 네트워크 원인 안내가 표시된다.

## 2. 출퇴근 기본 UI

1. 태블릿을 재실행한다.
2. 출퇴근 탭이 기본으로 선택되는지 확인한다.
3. 상단 제목 중복 없이 좌측 배너, 연결 상태, 탭, 안내, 입력 패널이 순서대로 보이는지 확인한다.

### 기대 결과

- 출퇴근 탭은 흰색 활성 카드와 blue 텍스트로 구분된다.
- 전화번호 입력 카드와 `직원 확인` 버튼 사이에 충분한 여백이 있다.
- 휴가 신청 탭 값이 출퇴근 입력 카드에 남아 있지 않는다.

## 3. 출퇴근 숫자 키패드

1. 전화번호 뒷 4자리 입력 카드를 누른다.
2. bottom sheet 숫자 키패드가 올라오는지 확인한다.
3. 숫자 4자리를 입력한다.
4. 삭제 버튼을 한 번 누르고 다시 숫자를 입력한다.
5. `입력 완료`을 누른다.

### 기대 결과

- 시스템 키보드가 표시되지 않는다.
- 숫자 키패드는 큰 버튼·삭제·취소·입력 완료 CTA를 제공한다.
- 완료 즉시 출퇴근 입력 카드에 4자리 값이 표시된다.
- 입력값은 휴가 신청 탭의 8자리 입력값과 독립적으로 유지된다.

## 4. 출근 또는 퇴근 저장

1. 출퇴근 4자리 입력 후 `직원 확인`을 누른다.
2. 직원 확인 모달의 이름과 다음 행동을 확인한다.
3. `다시 입력`을 눌러 모달이 닫히는지 확인한다.
4. 다시 직원 확인을 진행한다.
5. 모달의 `완료`를 누른다.

### 기대 결과

- `직원명님이 맞나요?`가 표시된다.
- 완료 전에는 출퇴근 기록이 저장되지 않는다.
- 완료 후 출근 또는 퇴근 기록이 저장되고 성공 알림이 표시된다.
- 성공 후 출퇴근 4자리 입력값은 초기화된다.

## 5. 휴가 신청 UI와 날짜 선택

1. 휴가 신청 탭을 누른다.
2. 전화번호 뒷 8자리 입력 카드를 확인한다.
3. 휴가 날짜 카드를 누른다.
4. 달력 모달에서 오늘 이후 날짜를 선택한다.
5. 연차·오전 반차·오후 반차 카드를 각각 눌러 본다.

### 기대 결과

- 휴가 탭은 흰색 활성 카드와 blue 텍스트로 표시된다.
- 달력 모달에서 날짜를 터치해 선택할 수 있다.
- 선택된 날짜가 휴가 날짜 카드에 즉시 반영된다.
- 휴가 종류는 직사각형 카드로 표시된다.
- 선택 카드는 연한 blue 배경, 진한 blue 테두리, 미세한 그림자로 구분된다.

## 6. 휴가 신청 직원 확인 및 저장

1. 전화번호 뒷 8자리, 날짜, 휴가 종류를 입력한다.
2. `직원 확인`을 누른다.
3. 직원 확인 모달의 이름·휴가 신청 안내를 확인한다.
4. `완료`를 누른다.

### 기대 결과

- 날짜 또는 8자리 전화번호가 빠진 경우 저장되지 않고 안내가 표시된다.
- 확인 모달 완료 전에는 휴가 신청이 저장되지 않는다.
- 완료 후 Supabase 휴가 신청 데이터가 생성된다.
- 성공 메시지가 표시되고 휴가 전화번호·날짜 입력값이 초기화된다.

## 7. 관리자 웹 반영 확인

1. 관리자 웹 앱에 로그인한다.
2. 홈 대시보드의 실시간 출퇴근을 확인한다.
3. 직원 상세의 최근 출퇴근 기록을 확인한다.
4. 휴가·연차 메뉴에서 새 휴가 신청을 확인한다.
5. 휴가 요청을 승인 또는 반려한다.

### 기대 결과

- 태블릿 출퇴근 기록이 직원 상태와 최근 기록에 반영된다.
- 휴가 신청이 승인 대기 항목으로 표시된다.
- 승인·반려 후 요청 상태가 갱신된다.

## 8. 회귀 및 오류 시나리오

| 상황 | 기대 결과 |
|---|---|
| 잘못된 4자리/8자리 | 직원 미확인 안내, 저장 없음 |
| 태블릿 연결 만료 | 재연결 안내 |
| 네트워크 끊김 | 실패 안내, 입력값 유지 |
| 이미 출근한 직원 | 다음 행동이 퇴근으로 표시 |
| 이미 퇴근한 직원 | 정책에 맞는 안내 표시 |
| 휴가 날짜 미선택 | 직원 확인 전 입력 안내 |
| 탭을 여러 번 전환 | 출퇴근 4자리와 휴가 8자리 값이 섞이지 않음 |
| 가로·세로 화면 전환 | 버튼과 입력 영역이 화면 밖으로 잘리지 않음 |

## 최종 합격 기준

- 관리자 연결, 출퇴근 저장, 휴가 신청 저장이 모두 성공한다.
- 키패드 입력과 입력 카드 반영이 즉시 작동한다.
- 완료 전 직원 확인 모달이 항상 표시된다.
- 웹 관리자에서 태블릿 데이터가 확인된다.
- 중복 제목, 잘린 화면, 시스템 키보드 간섭이 없다.
