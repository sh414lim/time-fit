# 실제 사업장 온보딩 UAT 실행 결과

실행일: 2026-08-12  
환경: Vercel Production

## 테스트 사업장

- 총관리자: `최종 가입 관리자`
- 사업장: `최종 가입 테스트 사업장`
- 직접 등록 직원: `온보딩 직접 직원`
- 태블릿: 해당 사업장 전용 URL

## 결과

| ID | 결과 | 확인 내용 |
| --- | --- | --- |
| OWN-01 | PASS | 기존 총관리자 계정으로 사업장 전용 관리자 홈 진입 |
| OWN-02 | PASS | 운영 설정에서 PIN·태블릿 URL 확인 |

| LEA-01/02 | 기존 PASS | 태블릿 휴가 신청·관리자 최신 요청 조회는 이전 API 재검증에서 통과 |
| ISO-01/02 | 기존 PASS | 다른 사업장 관리자·직원 계정에서 데이터 격리 통과 |

## 판정

총관리자 사업장 온보딩, 직접 직원 등록, 태블릿 출퇴근, 관리자 근태 조회는 실제 사업장 흐름으로 통과했다.

서브 관리자의 가입·등록·권한 위임은 현재 별도 역할/초대 UI 및 RLS 모델이 없어 **출시 필수 요구사항일 경우 출시 보류**다. 총관리자만 운영하는 MVP라면 현재 범위에서 운영 가능하다.
