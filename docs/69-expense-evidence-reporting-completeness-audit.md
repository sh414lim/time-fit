# TimeFit 지출·증빙·결산보고 완성도 점검

작성일: 2026-09-10  
검토 기준: 기획·로드맵에 기능이 존재하는지뿐 아니라 데이터 원천, 산식, 화면, 출력, 마감, 예외, 테스트가 모두 정의됐는지 확인

## 1. 결론

**설계 완성도: 구현 착수 가능 수준. 실제 제품 완성도: 아직 미구현 영역이 많아 출시 불가.**

기존 기획에는 일간·주간·월간·연말 결산의 방향과 항목은 있었으나 순익 명칭·산식, 차트 계약, PDF 보고서, 잠정/확정 표현이 부족했다. 해당 누락은 `docs/67-expense-card-development-roadmap-and-implementation-spec.md`의 21~24장에 보완했다.

현재 기준으로 제품 설계는 다음 전체 흐름을 포함한다.

```text
카드·영수증·매출·급여 수집
→ 정규화·중복 제거
→ 확정 지출 원장
→ 일/주/월/연 집계
→ 순익 차트
→ 마감·스냅샷
→ PDF/Excel/ZIP 보고서
→ 원본 증빙까지 추적
```

## 3. 보고 기능 완전성

### 일간

포함됨: 매출, 취소·할인, 지출, 인건비, 운영순익, 순익률, 증빙률, 동기화 상태, 전일/동요일 비교, 예외 조치.

판정: 설계 완료. POS 영업일 cutoff와 카드 잠정액 표시가 구현 핵심.

### 주간

포함됨: 일별 추이, 전주 비교, 계정과목/가맹점/직원별 지출, 예정·실제 인건비, 증빙 누적, 일간 합계 정합성 검사.

판정: 설계 완료. 조직별 주 시작 요일 설정 필요.

### 월간

포함됨: 순매출, 지출, 인건비, 운영순익, 전월/전년 비교, 카드 상태, 증빙 완결성, 마감 경고, 조정·재오픈, 세무 자료.

판정: 설계 완료. 운영 화면은 승인 잠정, 월마감은 매입 확정이라는 기준을 적용.

### 연말

포함됨: 월별 추이, 전년 비교, 분류별 합계, 증빙·장애·조정·재오픈 이력, 세무 원장 패키지.

판정: 설계 완료. 세무 신고서가 아니라 신고 준비 자료임을 명시.

## 4. 순익 차트 판정

`순이익`이라는 회계 용어 대신 1차 제품은 다음 숫자를 사용한다.

```text
운영순익(추정) = 순매출 - 확정 운영지출 - 실제 인건비
```

매출원가가 연결된 조직에만 `영업이익(추정)` 산식을 선택적으로 제공한다. 법인세·감가상각·금융손익을 포함하지 않으므로 당기순이익으로 표시하지 않는다.

필수 차트 8개, 잠정/확정 시각 구분, 누락 구간 경고, 거래/영수증 drill-down, 공통 snapshot version이 정의됐다.

판정: 설계 완료. 같은 집계 API를 화면·PDF·Excel이 공유해야 숫자 불일치를 방지할 수 있다.

## 5. 결산 보고서 판정

출력 형식은 웹, PDF, Excel, ZIP으로 정의했다. PDF 7개 섹션과 Excel 8개 sheet, 마감 버전 보존, 재오픈 버전 증가, signed URL, 다운로드 감사 기록을 포함한다.

판정: 설계 완료. 문서 생성 worker와 한글 렌더링 시각 QA는 구현 단계에서 필요하다.

## 6. 완벽성을 위한 필수 조건

다음 중 하나라도 빠지면 지출·증빙 기능이 완성됐다고 판정하지 않는다.

1. 카드 API·CSV·이메일·영수증 중복 유입이 한 지출로 수렴한다.
2. 카드 취소·부분취소·지연매입의 순액이 정확하다.
3. 화면 KPI·차트·PDF·Excel 합계가 모두 같다.
4. 잠정 데이터와 확정 데이터를 사용자가 구분할 수 있다.
5. 모든 숫자에서 원장과 원본 영수증까지 이동할 수 있다.
6. 마감된 보고서는 이후 동기화로 변경되지 않는다.
7. 마감 후 변경은 재오픈 또는 조정으로 기록된다.
8. 누락·동기화 실패·미증빙이 보고서에서 숨겨지지 않는다.
9. 조직별 RLS와 signed URL 격리를 통과한다.
10. API 장애 중 CSV 운영 후 복구해도 합계가 유지된다.

## 7. 최종 판단

기획 관점에서는 카드 연결부터 보고서 생성까지 전체 체인이 이제 연결되어 있다. 다만 현재 코드에는 카드 수동 등록·기초 CSV·파일 보관만 일부 존재하므로, 실제 서비스가 완벽히 구성된 상태는 아니다.

개발 완료 판정은 다음 E2E 한 문장으로 검증한다.

> 카드 결제와 영수증 촬영 후 거래가 중복 없이 지출 원장에 확정되고, 해당 금액이 일간·주간·월간 운영순익 차트와 마감 PDF/Excel에 동일하게 나타나며, 숫자를 눌러 원본까지 추적할 수 있다.
