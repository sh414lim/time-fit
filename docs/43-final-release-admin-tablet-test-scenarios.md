# TimeFit 관리자·태블릿 종합 최종 테스트 시나리오

## 1. 테스트 목적

관리자 웹, 네이티브 Android 태블릿, Supabase 실제 데이터, 출퇴근·휴가 승인 흐름을 하나의 운영 시나리오로 검증한다. 본 문서는 MVP 종합 배포 직전 최종 승인 기준으로 사용한다.

## 2. 테스트 환경

| 구분 | 기준 |
|---|---|
| 관리자 웹 | `https://timefit-omega.vercel.app/` |
| 웹 브라우저 | Chrome/Safari 최신 버전, 모바일·데스크톱 |
| 태블릿 웹 fallback | `https://timefit-omega.vercel.app/tablet` |
| 네이티브 앱 | `timefit-tablet.apk` 테스트 Release APK |
| 관리자 계정 | `ceo1@leofittech.com` |
| 테스트 직원 | 임세환 |
| 직원 뒷 4자리 | 4724 |
| 직원 뒷 8자리 | 99154724 |
| 테스트 사업장 | 레오핏테크 |

실제 운영 데이터 변경 케이스는 테스트 날짜와 대상 직원을 사전에 확인하고 실행한다.

## 3. 테스트 데이터 사전 조건

- 관리자 계정이 레오핏테크 사업장 manager 권한을 가진다.
- 테스트 직원에 이름, 직책, 급여 유형, 입사일, 전화번호 전체가 저장되어 있다.
- `phone_last4`, `phone_last8` 값이 자동 생성되어 있다.
- 테스트 태블릿을 연결할 수 있고 기존 폐기 토큰이 남아 있지 않다.
- 테스트 대상 휴가 날짜는 정기휴일·공휴일이 아닌 미래 날짜다.
- 테스트 전 현재 출퇴근·휴가 데이터를 백업하거나 테스트 결과를 기록한다.

## 5. 관리자 실제 데이터 변경 테스트

### ADM-W01 직원 정보 수정

1. 직원 상세에서 테스트 직원 전화번호를 `01099154724`로 저장한다.
2. 저장 성공 모달을 확인한다.
3. 목록과 상세 페이지에서 전화번호 뒷 4자리·8자리가 갱신됐는지 확인한다.

### ADM-W02 연차 직접 부여

1. 테스트 직원 상세에서 연차 1일을 부여한다.
2. 부여 성공 알림을 확인한다.
3. 연차 잔여와 부여 이력에 1일이 반영되는지 확인한다.

### ADM-W03 스케줄 일괄 등록

1. 직원 1명 이상을 선택한다.
2. 미래 날짜 2개 이상을 선택한다.
3. 근무 형태·시작·종료 시간을 입력한다.
4. 충돌 확인 후 저장한다.
5. 선택한 모든 직원×날짜 조합이 저장되는지 확인한다.

### ADM-W04 스케줄 수정·삭제

1. 등록 일정의 수정 버튼을 누른다.
2. 시간 또는 근무 형태를 수정하고 저장한다.
3. 일정이 갱신되는지 확인한다.
4. 삭제 후 월간·주간·직원 상세에서 제거되는지 확인한다.

## 7. 태블릿 출퇴근 실제 변경 테스트

### TAB-A01 출근

1. 출퇴근 탭에서 뒷 4자리 `4724`를 입력한다.
2. 직원 확인을 누른다.
3. `임세환님이 맞나요?` 확인 모달을 확인한다.
4. 출근하기를 누른다.
5. 성공 모달과 입력 초기화를 확인한다.
6. 관리자 웹 출퇴근 화면에서 임세환 상태가 근무 중으로 변경됐는지 확인한다.

### TAB-A02 퇴근

1. 같은 번호로 직원을 조회한다.
2. 퇴근하기를 누른다.
3. 성공 모달을 확인한다.
4. 관리자 웹에서 퇴근 시각과 근무 시간이 반영됐는지 확인한다.

### TAB-A03 오류 케이스

- 미등록 뒷자리: 직원 미등록 안내
- 이미 출근한 상태에서 출근 재시도: 중복 기록 차단
- 퇴근 완료 후 재퇴근: 중복 기록 차단
- 네트워크 차단: 재시도 안내와 데이터 중복 저장 없음

## 8. 태블릿 휴가 신청 실제 변경 테스트

### TAB-L01 정상 신청

1. 휴가 신청 탭으로 이동한다.
2. 뒷 8자리 `99154724`를 입력한다.
3. 미래 평일을 선택한다.
4. 연차 또는 반차 카드를 선택한다.
5. 신청하기를 누른다.
6. 신청 완료 모달과 신청 상태를 확인한다.
7. 관리자 웹 휴가 관리에서 승인 대기 요청이 표시되는지 확인한다.

### TAB-L02 관리자 승인

1. 관리자 웹에서 승인 대기 요청을 연다.
2. 신청 직원·날짜·휴가 유형을 확인한다.
3. 승인하기를 누른다.
4. 승인 완료 상태가 표시되는지 확인한다.
5. 월간 스케줄과 직원 상세 연차 내역에 반영되는지 확인한다.

### TAB-L03 관리자 반려

1. 새 테스트 휴가 신청을 생성한다.
2. 관리자 웹에서 반려와 사유를 저장한다.
3. 반려 상태와 사유가 관리자·직원 화면에 표시되는지 확인한다.

### TAB-L04 휴가 차단 조건

- 정기휴일 신청: 차단 안내
- 운영 설정에 등록한 공휴일 신청: 차단 안내
- 연차 잔여 부족: 신청 차단
- 과거 날짜: 신청 차단
- 뒷 8자리 미등록: 직원 미등록 안내

## 10. 보안·격리 테스트

- 다른 사업장 직원 전화번호로 조회되지 않는다.
- 태블릿 토큰을 폐기하면 모든 RPC가 거부된다.
- 관리자 로그아웃 후 웹 데이터가 초기화된다.
- 태블릿 앱에 관리자 비밀번호가 남지 않는다.
- 오류 로그에 전체 전화번호·비밀번호·토큰이 기록되지 않는다.
- 직원은 관리자 급여·전체 직원 정보에 접근할 수 없다.

## 11. 출시 승인 기준

### P0 필수 통과

- 관리자 로그인·사업장 격리
- 태블릿 연결 및 토큰 복구
- 출근·퇴근 저장과 관리자 반영
- 휴가 신청·승인·반려와 관리자 반영
- 월간 전체 날짜 표시
- 직원 전화번호 뒷 4자리·8자리 인증
- 로딩·오류·중복 제출 방지

### P1 출시 전 확인

- Android 실기기 2종 이상
- iPad 실기기 1종 이상
- 네트워크 단절·복구
- 공휴일·정기휴일 차감
- 앱 재실행·화면 회전·장시간 대기

### 출시 보류 조건

- 출퇴근 또는 휴가 데이터가 관리자 화면에 반영되지 않음
- 다른 사업장 데이터 노출
- 태블릿 토큰 폐기 후 접근 가능
- 월간 보기 날짜 누락
- 휴가 차단 조건 우회 가능

## 12. 직원 등록·관리 종합 테스트

### EMP-01 직원 초대 등록

1. 관리자 웹에서 `직원 초대`를 선택한다.
2. 직원 이름, 이메일 또는 초대 식별 정보, 직책, 부서를 입력한다.
3. 초대를 발송한다.
4. 초대 성공 알림과 초대 상태를 확인한다.
5. 직원이 초대를 수락하면 동일 사업장의 employee role로 생성되는지 확인한다.
6. 관리자 직원 목록에 재직 상태로 표시되는지 확인한다.

### EMP-02 관리자 직접 직원 등록

1. `직원 등록하기`를 선택한다.
2. 이름, 전화번호, 직책, 부서, 시급·월급 유형, 급여, 재직 시작일을 입력한다.
3. 저장한다.
4. 동일 직원이 직원 목록과 직원 상세에 표시되는지 확인한다.
5. `registration_type=manual` 또는 이에 준하는 직접 등록 상태가 저장되는지 확인한다.
6. 이후 직원 계정 초대·연결 시 기존 직원 레코드와 중복 생성되지 않는지 확인한다.

### EMP-03 필수값·급여 검증

- 이름 누락: 저장 차단
- 전화번호 형식 오류: 저장 차단
- 시급제인데 시급 누락: 저장 차단
- 월급제인데 월급 누락: 저장 차단
- 재직 시작일이 미래: 정책에 맞는 안내 표시
- 중복 전화번호: 기존 직원 확인 또는 저장 차단

### EMP-04 직원 정보 수정

1. 직원 목록에서 직원을 클릭해 상세 페이지를 연다.
2. 이름, 전화번호, 직책, 부서, 급여 유형, 급여, 재직 시작일을 수정한다.
3. 저장 성공 알림을 확인한다.
4. 목록·상세·급여·스케줄 화면에 수정값이 일관되게 반영되는지 확인한다.
5. 전화번호 수정 후 `phone_last4`, `phone_last8`이 재생성되는지 확인한다.

### EMP-05 직원 비활성화·재직 상태

1. 테스트 직원을 퇴사 또는 비활성 상태로 변경한다.
2. 직원 목록의 상태가 변경되는지 확인한다.
3. 비활성 직원이 신규 스케줄·휴가 신청 대상에서 제외되는지 확인한다.
4. 과거 출퇴근·급여·휴가 이력은 유지되는지 확인한다.
5. 재직 상태 복구 후 다시 스케줄 대상에 노출되는지 확인한다.

### EMP-06 직원 상세 데이터 통합

직원 상세 페이지에서 다음 항목을 모두 확인한다.

- 기본정보: 이름, 전화번호, 부서, 직책, 재직 상태
- 급여정보: 시급·월급 유형, 금액
- 스케줄: 주간 일정, 전체 보기 이동
- 출퇴근: 최근 기록과 근무 시간
- 휴가: 발생·사용·잔여 일수, 신청·승인·반려 이력
- 연차 부여: 관리자 직접 부여 이력

### EMP-07 권한·개인정보 보호

- 관리자는 전체 직원 정보와 급여를 볼 수 있다.
- 직원은 본인 정보와 본인 스케줄·휴가만 볼 수 있다.
- 직원 계정으로 직원 등록·급여 수정·연차 부여가 불가능하다.
- 다른 사업장 관리자는 해당 직원 정보를 조회할 수 없다.
- 직원 상세 전화번호는 관리자 화면에서만 전체 확인 가능하고, 태블릿에는 필요한 뒷자리만 사용한다.

### EMP-08 직원 데이터와 태블릿 연동

1. 관리자 상세에서 테스트 직원 전화번호를 저장한다.
2. 태블릿에서 새 뒷 4자리로 출퇴근 조회한다.
3. 뒷 8자리로 휴가 신청 직원을 조회한다.
4. 변경 전 번호가 더 이상 인증되지 않는지 확인한다.
5. 변경 후 번호로만 출퇴근·휴가 신청이 가능한지 확인한다.
