# TimeFit 클라이언트 요구사항 정리

> 목적: 현재 근태·휴가·스케줄 MVP를 급여 정산과 세무 협업까지 연결하는 다음 개발 단계의 요구사항을 정리한다.

## 1. 급여 및 스케줄 정리

### 요구사항

- 직원별 근무 스케줄, 실제 출퇴근 기록, 휴가·휴무를 한 기준으로 집계한다.
- 시급제·월급제·일급제별 예상 급여와 확정 급여를 구분해 보여 준다.
- 연장·야간·휴일 근무 여부와 휴게시간을 급여 산정 근거로 확인할 수 있어야 한다.
- 월별 급여 마감 전 관리자 검토 및 수정 이력을 남긴다.

### 화면·기능 범위

- 급여 관리: 직원별 근무시간, 기본급, 수당, 공제, 예상 실수령액, 상태(작성 중/검토 완료/마감).
- 직원 상세: 기간별 근무·휴가·급여 산정 근거 조회.
- 월별 정산: 전체 직원 합계, 인건비 추이, CSV·엑셀 내보내기.

### 확인 필요

- 급여 기준일, 급여 지급일, 주급·월급 운영 여부.
- 연장·야간·휴일근로의 산정 규칙과 수당률.
- 무급 휴게시간, 결근, 지각, 조기퇴근의 공제 규칙.

## 2. 월말 정산 세무 서류 자동 정리

### 요구사항

- 급여 마감 데이터를 기준으로 월말 세무 정산용 자료를 자동 생성한다.
- 세무사 전달용 요약표와 직원별 상세 자료를 분리한다.
- 생성 시점, 대상 기간, 작성자, 수정 이력을 보관한다.

### 산출물 후보

- 급여대장, 급여명세서 데이터, 근태 집계표.
- 직원별 지급·공제 내역, 사업장 월간 인건비 요약.
- 4대보험 및 원천세 신고를 위한 기초 데이터 파일.

### 유의사항

- 법정 신고 양식과 전자신고 연동은 세무사·노무사 검토 후 확정한다.
- 자동 생성 자료는 “신고 초안”으로 표시하고, 최종 신고 책임 주체와 승인 절차를 분리한다.

## 3. 퇴직금·4대보험·세금 계산

### 요구사항

- 직원의 입·퇴사일, 급여 형태, 근무 이력을 바탕으로 퇴직금 예상액을 계산한다.
- 국민연금, 건강보험, 장기요양보험, 고용보험, 산재보험 및 원천세 관련 공제 예상액을 관리한다.
- 법률·요율 변경 시 계산 기준의 버전과 적용일을 관리한다.

### 구현 원칙

- 서비스는 예상값과 산정 근거를 제공하고, 최종 확정은 관리자 또는 세무 담당자가 승인한다.
- 직원별 예외 계약, 비과세 항목, 중도 입·퇴사, 휴직, 상한·하한은 별도 규칙으로 관리한다.
- 계산 엔진은 정책 테이블 기반으로 설계해 매년 요율 변경에 대응한다.

### 확인 필요

- 직원 고용 형태 및 4대보험 가입 대상 기준.
- 비과세 수당, 상여, 식대, 교통비 등 급여 항목.
- 퇴직금 중간정산 및 퇴직연금 운영 여부.

## 4. 세무사 이메일 발송

### 요구사항

- 월별 마감 후 지정 세무사에게 정산 자료를 이메일로 발송한다.
- 발송 전 관리자 미리보기·승인을 거치고, 발송 이력과 첨부 파일 목록을 보관한다.
- 수신자, 참조자, 제목·본문 템플릿을 사업장별로 설정한다.

### 기능 흐름

1. 관리자가 정산 기간을 선택한다.
2. 시스템이 정산 자료를 생성한다.
3. 관리자가 자료·수신자를 검토하고 발송 승인한다.
4. 이메일을 발송하고 성공·실패 상태를 기록한다.

### 연동 후보

- Resend, SendGrid, Amazon SES 또는 회사 SMTP.
- 파일 보관용 Supabase Storage 또는 별도 문서 저장소.

## 5. 카카오 알림톡

### 요구사항

- 휴가 신청, 승인, 반려, 스케줄 변경, 급여명세서 발행 등 주요 이벤트를 알림톡으로 발송한다.
- 관리자와 직원의 수신 동의·전화번호·알림 설정을 관리한다.
- 메시지 템플릿 승인 상태, 발송 대기·성공·실패 이력을 조회한다.

### 우선 알림 이벤트

- 직원 휴가 신청 → 관리자.
- 휴가 승인·반려 → 신청 직원.
- 스케줄 등록·변경·취소 → 대상 직원.
- 급여 마감·급여명세서 준비 완료 → 대상 직원.

### 유의사항

- 알림톡은 카카오 승인 템플릿 및 공식 발송 대행사 연동이 필요하다.
- 실패 시 문자 대체 발송 여부와 비용 정책을 결정해야 한다.

## 6. 스케줄표 작성 및 직관적 확인 UI

### 요구사항

- 일간·주간·월간 보기에서 직원별 근무, 휴무, 휴가를 빠르게 확인한다.
- 여러 직원과 여러 날짜를 동시에 선택해 일괄 스케줄을 등록·수정한다.
- 근무 형태별 색상, 파트별 필터, 인원 부족 경고를 제공한다.
- 모바일 직원 화면은 개인 스케줄을 우선 표시하고, 관리자 화면은 전체 운영 현황을 우선 표시한다.

### UX 기준

- 스케줄 카드 클릭 시 직원 상세 또는 일정 편집으로 이동한다.
- 월간 보기에서도 모든 날짜의 근무·휴무·휴가 집계가 보인다.
- 등록·수정·삭제 후 로딩 상태와 완료·오류 알림을 제공한다.

## 7. 직원 관리 및 스케줄 파트별 분리

### 요구사항

- 사업장 내 부서·파트·직무를 관리하고, 직원에게 복수 또는 기본 파트를 지정한다.
- 스케줄 화면에서 파트별로 필터·그룹화해 필요한 인력 현황을 확인한다.
- 관리자는 파트별 관리자 권한을 부여해 담당 파트의 직원·스케줄만 관리하도록 확장할 수 있어야 한다.

### 데이터 설계 방향

- `파트`: 사업장별 이름, 색상, 정렬 순서, 활성 상태.
- `직원-파트`: 직원, 파트, 기본 파트 여부, 적용 시작·종료일.
- `스케줄`: 직원·날짜·근무 형태 외에 파트 또는 근무 위치를 선택적으로 저장.
- `권한`: 전체 관리자, 파트 관리자, 직원으로 구분.

## 권장 개발 우선순위

| 우선순위 | 범위 | 목표 |
| --- | --- | --- |
| P0 | 스케줄·근태 데이터 정합성, 파트 관리, 급여 기초 집계 | 급여 산정의 신뢰 가능한 원천 데이터 확보 |
| P1 | 급여 마감, 급여대장·세무사 전달 파일, 이메일 발송 | 월말 정산 업무 단축 |
| P2 | 4대보험·세금·퇴직금 예상 계산 | 관리자 의사결정 지원 |
| P3 | 알림톡 자동화, 전자신고·외부 세무 서비스 연동 | 운영 자동화 확대 |

## 다음 확정이 필요한 정보

1. 실제 급여 항목과 급여 계산 규칙.
2. 세무사 수신 이메일, 원하는 파일 형식, 월 마감 프로세스.
3. 사용할 카카오 알림톡 발송 대행사와 승인 템플릿.
4. 부서·파트 구조 및 파트별 관리자 권한 범위.
5. 세금·4대보험·퇴직금의 최종 검토 담당자.
