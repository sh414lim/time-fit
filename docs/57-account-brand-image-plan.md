# 계정별 대표 이미지 업로드 및 메인 브랜딩 적용 기획

사업장별 로고 또는 대표 이미지를 운영 설정에서 등록해 관리자 웹, 직원 웹, 태블릿의 공통 브랜드 영역에 표시한다.

## 데이터 구조

조직 데이터에는 대표 이미지 파일 경로와 최신 업로드 시각을 저장한다. 비공개 Storage bucket `timefit-organization-branding`을 사용한다. PNG, JPG, WEBP만 허용하며 최대 용량은 5MB로 제한한다. 해당 사업장 관리자는 업로드, 교체, 삭제할 수 있고 소속 직원과 연결 태블릿은 서명 URL로 조회만 할 수 있다.

## 관리자 흐름

운영 설정의 사업장 브랜딩에서 이미지를 선택한다. 저장 전 정사각형 미리보기와 자동 중앙 크롭 결과를 확인한다. 저장하면 이전 이미지를 안전하게 교체하고 서명 URL을 갱신한다. 헤더의 TimeFit 로고 옆, 사이드바 사업장 정보, 태블릿 왼쪽 배너에 즉시 반영한다. 이미지가 없으면 기존 TimeFit 기본 로고와 사업장명을 표시한다.

## 성능과 보안

표시는 256px 정사각형 WebP 변형본을 사용해 로딩을 줄인다. 브라우저에는 이미지 바이너리를 저장하지 않고 서명 URL만 짧게 캐시한다. URL은 한 시간 뒤 만료되며 사업장 전환이나 로그아웃 때 폐기한다. 이미지 교체 시 이전 파일은 서버 작업으로 삭제해 Storage 누적을 막는다.

## 구현 순서

조직 테이블과 Storage bucket 및 RLS 정책을 추가한다. 이어 업로드 API와 서버 측 리사이즈 및 파일 검증을 구현하고, 운영 설정의 업로드와 미리보기 화면을 만든다. 마지막으로 관리자, 직원, 태블릿 브랜드 영역을 연결하고 사업장별 권한과 이미지 교체를 E2E 검증한다.
