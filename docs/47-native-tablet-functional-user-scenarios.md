# TimeFit 태블릿 기능 사용자 시나리오

## 목적

태블릿에서 수행한 출퇴근·휴가 신청이 Supabase에 정확히 저장되고, 관리자 웹에서 즉시 확인·처리되는지 검증한다.

## 역할

- 관리자: 사업장 생성, 태블릿 연결, 직원·출퇴근·휴가 요청 관리
- 직원: 태블릿에서 전화번호 입력으로 출퇴근 및 휴가 신청
- 태블릿: 관리자 연결 토큰을 보유한 사업장 전용 기기

## F-01. 관리자 태블릿 연결

### 사전 조건

- 관리자 계정에 사업장 및 관리자 권한이 있다.
- 태블릿은 인터넷에 연결되어 있다.

### 흐름

1. 관리자가 태블릿 앱을 처음 실행한다.
2. 관리자 이메일과 비밀번호를 입력한다.
3. 사업장 태블릿 연결을 완료한다.
4. 앱을 종료 후 재실행한다.

### 기대 결과

- 기기 토큰이 로컬에 저장된다.
- 관리자 인증 세션은 태블릿에 남지 않는다.
- 재실행 시 출퇴근 탭이 기본 화면으로 열린다.
- 연결된 기기는 관리자 웹 운영 설정에서 확인 가능하다.

## F-02. 출근 기록

### 사전 조건

- 태블릿이 사업장에 연결되어 있다.
- 직원의 전체 전화번호가 관리자 웹에 등록되어 있다.

### 흐름

1. 직원이 출퇴근 탭에서 전화번호 뒷 4자리를 입력한다.
2. 직원 확인을 누른다.
3. 직원명과 `출근 기록이 저장됩니다` 안내가 있는 확인 모달을 확인한다.
4. 완료를 누른다.

### 기대 결과

- `timefit_user_tablet_attendance_v2`가 `check_in`으로 호출된다.
- 오늘의 출근 시간이 저장된다.
- 성공 후 출퇴근 4자리 입력값이 초기화된다.
- 관리자 홈의 오늘 출근·현재 근무 중 수치가 갱신된다.
- 직원 상세의 최근 출퇴근 기록에 출근 시간이 표시된다.

## F-03. 퇴근 기록

### 사전 조건

- 동일 직원에게 당일 출근 기록이 있다.

### 흐름

1. 직원이 전화번호 뒷 4자리를 다시 입력한다.
2. 직원 확인을 누른다.
3. 모달에서 `퇴근 기록이 저장됩니다`를 확인한다.
4. 완료를 누른다.

### 기대 결과

- 같은 직원의 다음 행동이 `check_out`으로 안내된다.
- 퇴근 시간과 근무시간이 기록된다.
- 관리자 홈에서 직원 상태가 `퇴근 완료`로 변경된다.
- 현재 근무 중 인원이 감소한다.

## F-04. 휴가 신청

### 사전 조건

- 직원 전화번호가 등록되어 있다.
- 태블릿이 연결되어 있다.

### 흐름

1. 직원이 휴가 신청 탭으로 이동한다.
2. 전화번호 뒷 8자리를 입력한다.
3. 달력 모달에서 오늘 이후 날짜를 선택한다.
4. 연차·오전 반차·오후 반차 중 하나를 선택한다.
5. 직원 확인을 누른다.
6. 직원명과 선택한 휴가 신청 안내가 있는 모달을 확인한다.
7. 완료를 누른다.

### 기대 결과

- `timefit_user_tablet_leave_request_v2`가 호출된다.
- 휴가 요청이 `pending` 상태로 저장된다.
- 신청 완료 후 휴가용 8자리와 날짜가 초기화된다.
- 출퇴근용 4자리 입력값은 변경되지 않는다.
- 관리자 웹 휴가·연차 메뉴에서 승인 대기 요청으로 표시된다.

## F-05. 관리자 휴가 승인

### 흐름

1. 관리자가 웹에서 휴가·연차 메뉴를 연다.
2. 태블릿에서 신청된 요청을 선택한다.
3. 승인 또는 반려를 선택한다.

### 기대 결과

- 요청 상태가 `approved` 또는 `rejected`로 변경된다.
- 승인 시 직원 상세의 연차 사용·잔여 수치에 반영된다.
- 반려 시 휴가 차감은 발생하지 않는다.
- 처리 결과가 새로고침 후에도 유지된다.

## F-06. 출퇴근·휴가 입력값 분리

### 흐름

1. 출퇴근 탭에 전화번호 뒷 4자리를 입력하고 완료한다.
2. 휴가 탭으로 이동한다.
3. 휴가용 8자리를 입력하고 완료한다.
4. 출퇴근 탭으로 돌아간다.

### 기대 결과

- 출퇴근 탭에는 4자리 값만 표시된다.
- 휴가 탭에는 8자리 값만 표시된다.
- 한 탭의 입력값이 다른 탭의 입력값을 덮어쓰지 않는다.

## F-07. 입력 완료 전 저장 방지

### 흐름

1. 직원이 번호·날짜를 입력한다.
2. 확인 모달에서 `다시 입력`을 누른다.
3. 관리자 웹을 새로고침해 데이터 상태를 확인한다.

### 기대 결과

- 출퇴근·휴가 데이터가 생성되지 않는다.
- 확인 모달의 `완료`를 누른 경우에만 저장된다.

## F-08. 오류 처리

| 조건 | 기대 결과 |
|---|---|
| 등록되지 않은 전화번호 | 직원 미확인 메시지, 저장 없음 |
| 4자리 미입력 | 출퇴근 확인 RPC 미호출 |
| 8자리 또는 날짜 미입력 | 휴가 신청 확인 모달 미표시 |
| 네트워크 실패 | 오류 메시지 표시, 입력값 유지 |
| 태블릿 토큰 만료 | 관리자 재연결 안내 |
| 이미 출근한 직원 | 다음 확인 모달에서 퇴근 동작 안내 |

## 기능 합격 기준

- 출근·퇴근·휴가 신청이 완료 버튼 이후에만 저장된다.
- 저장된 데이터가 관리자 웹에서 새로고침 후 확인된다.
- 출퇴근과 휴가의 전화번호 입력 상태가 분리된다.
- 오류 상황에서 중복 저장이나 잘못된 직원 매칭이 발생하지 않는다.
