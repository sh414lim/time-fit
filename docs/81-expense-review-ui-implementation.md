# 지출 증빙 확인 필요함 UI 구현

## 화면 구성

지출·증빙 상단에 `확인 필요 영수증` 영역을 추가했다. 관리자는 목록을 펼쳐 다음 정보를 한 화면에서 비교할 수 있다.

- 원본 영수증
- OCR 상호·거래일·금액·사업자번호
- 카드 별칭과 끝 4자리
- 카드 사용처·금액·거래일
- 금액·날짜·승인번호·카드번호별 매칭 점수

## 지원 작업

- OCR 추출값 수정
- 카드 후보 확정
- 잘못된 후보 반려
- 확정된 연결 해제
- 카드 후보가 없는 영수증의 지출 제외

확정 버튼에는 확인 절차를 두고, 확정된 후보가 있는 동안에는 지출 제외 버튼을 비활성화한다. 먼저 연결을 해제해야 제외할 수 있어 실수로 원장 연결을 잃지 않는다.

## 반응형 처리

데스크톱에서는 OCR 필드와 카드 후보를 밀도 있게 비교하고, 모바일에서는 폼과 후보 버튼을 단일 열 또는 2열로 재배치한다.

## 검증 결과

- Node 테스트 11개 통과
- Vite 프로덕션 빌드 통과
- Git whitespace 검사 통과

원격 DB 마이그레이션과 Google Vision 환경변수가 아직 적용되지 않았으므로 운영 데이터 기반 브라우저 검증은 배포 단계에서 진행한다.
