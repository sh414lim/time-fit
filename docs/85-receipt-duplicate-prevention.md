# 영수증 중복 등록 방지 구현

## 1단계: 동일 파일 차단

브라우저에서 영수증 이미지의 SHA-256을 계산하고 같은 조직에 동일 해시가 존재하는지 확인한다. 동일한 사진을 다시 선택하면 파일 업로드 전에 차단하므로 저장공간과 OCR·LLM 비용이 발생하지 않는다. 데이터베이스 고유 인덱스가 동시 업로드 경쟁도 다시 차단한다.

## 2단계: 내용 기반 중복 병합

크기 조정, 캡처, 재촬영으로 파일 해시가 달라져도 OCR 구조화 결과의 다음 필드로 영수증 지문을 생성한다.

- 거래일
- 총금액
- 사업자등록번호 우선, 없으면 승인번호 또는 상호
- 승인번호
- 카드 끝 4자리

같은 지문이 이미 기존 지출에 연결돼 있으면 새 지출을 만들지 않고 새 원본 문서만 기존 지출의 보조 증빙으로 연결한다.

## 운영 결과

- 동일 파일: 업로드·OCR·LLM 호출 전 차단
- 파일은 다르지만 같은 영수증: OCR 후 기존 지출에 병합
- 영수증과 카드 거래: 매칭 확정 시 동일 지출로 병합

따라서 하나의 소비가 파일 재등록, 영수증 재촬영, 카드 자동수집을 통해 여러 번 유입되어도 결산 지출은 한 번만 합산된다.
