# TimeFit 최종 사용자 사용 시나리오

## 목적

관리자 웹과 매장 태블릿을 함께 사용하는 실제 사업장의 하루 운영을 기준으로, 출시 전 사용 흐름과 확인 기준을 정의한다.

## 역할

| 역할 | 사용 화면 | 할 수 있는 일 |
| --- | --- | --- |
| 관리자 | 웹 관리자 | 사업장·직원·스케줄·근태·휴가·급여·운영 기준 관리 |
| 현장 직원 | 연결된 태블릿 | 전화번호 인증 출퇴근, 연차·반차 신청 |
| 초대 직원 | 직원 웹 화면 | 초대 수락 후 개인 스케줄·근태·휴가 내역 조회 |

## SC-01 관리자 가입과 사업장 생성

1. 관리자가 로그인 화면에서 `관리자 회원가입`을 선택한다.
2. 이름, 사업장명, 이메일, 비밀번호를 입력해 가입한다.
3. 이메일 인증 없이 계정과 사업장이 생성된다.
4. 관리자는 관리자 홈으로 이동하고 현재 사업장명을 확인한다.

**성공 기준:** 로그인 후 관리자 홈이 표시되고, 다른 사업장 데이터가 노출되지 않는다.

## SC-02 사업장 운영 기준 설정

1. 관리자가 `운영 설정`으로 이동한다.
2. 사업장명, 주소, 기본 휴게시간, 근무 형태를 저장한다.
3. 필요 시 근무 형태를 직접 입력해 추가한다.
4. 연차 발생일, 월차 조건, 정기휴일, 공휴일, 공휴일 근무 보상 기준을 설정한다.
5. 저장 후 페이지를 이동했다가 다시 돌아와 설정값을 확인한다.

**성공 기준:** 저장된 운영 기준이 스케줄·휴가 계산에 사용된다.

## SC-03 직원 직접 등록 및 초대 연동

1. 관리자가 `직원 관리 > 직원 등록하기`를 선택한다.
2. 이름, 전화번호, 부서, 직책, 급여 형태, 단가, 입사일을 입력한다.
3. 직원 목록과 상세 페이지에서 저장 내용을 확인한다.
4. 계정이 있는 직원은 초대를 수락한다.
5. 전화번호가 일치하면 기존 직접 등록 직원과 초대 계정이 하나의 직원 정보로 연결된다.

**성공 기준:** 관리자 상세 화면에서 전화번호·급여·입사일·연차·근태를 통합 확인할 수 있다.

## SC-04 스케줄 등록과 변경

1. 관리자가 `스케줄 > 근무 추가`를 선택한다.
2. 한 명 이상 직원과 한 개 이상 날짜를 달력에서 선택한다.
3. 근무 형태, 시작·종료 시간, 휴게시간을 입력하고 저장한다.
4. 일간·주간·월간 보기에서 일정이 표시되는지 확인한다.
5. 등록된 일정을 눌러 수정 또는 삭제한다.

**성공 기준:** 선택한 직원×날짜 조합이 저장되고, 월간 보기에서 해당 월 전체 일정 수가 확인된다.

## SC-05 관리자 태블릿 연결

1. 관리자가 웹 `운영 설정 > 태블릿 출퇴근`에서 새 태블릿 연결을 시작한다.
2. 태블릿 초기 화면에서 관리자 계정으로 로그인한다.
3. 소속 사업장을 선택해 연결을 완료한다.
4. 태블릿이 직원용 `출퇴근` 화면으로 전환되는지 확인한다.
5. 웹에서 태블릿 이름·연결 상태·최근 사용 시간을 확인한다.

**성공 기준:** 태블릿에는 관리자 정보가 남지 않고, 연결 해제 시 직원 업무 기능이 차단된다.

## SC-06 직원 태블릿 출근

1. 직원이 태블릿 `출퇴근` 탭에서 번호 입력 영역을 누른다.
2. 키패드 모달에 전화번호 뒤 4자리를 입력하고 `입력 완료`를 누른다.
3. 입력값이 화면에 반영된 뒤 `직원 확인`을 누른다.
4. 이름과 출근 가능 상태를 확인 모달에서 확인한다.
5. `출근 완료`를 누르고 결과 모달을 닫는다.

**성공 기준:** 웹 관리자 홈과 출퇴근 관리에 직원명·출근 시각·근무 중 상태가 반영된다.

## SC-07 직원 태블릿 퇴근

1. 근무 중인 직원이 동일한 번호 입력 절차를 진행한다.
2. 확인 모달에서 출근 시각과 `퇴근 완료` 동작을 확인한다.
3. 퇴근을 완료한다.

**성공 기준:** 웹 출퇴근 관리에 퇴근 시각과 실제 근무시간이 반영된다.

## SC-08 직원 태블릿 휴가 신청

1. 직원이 태블릿 `휴가 신청` 탭으로 이동한다.
2. 휴가 전용 키패드에 전화번호 뒤 8자리를 입력한다.
3. 날짜 입력 영역을 눌러 달력 모달에서 신청일을 선택한다.
4. 연차·오전 반차·오후 반차 중 하나를 선택한다.
5. `휴가 신청하기`를 누른다.
6. 직원명·날짜·휴가 종류·차감일을 확인한 뒤 `신청 완료`를 누른다.

**성공 기준:** 관리자 웹의 휴가·연차 화면에 승인 대기 요청이 생성된다.

## SC-09 관리자 휴가 승인·반려

1. 관리자가 홈의 승인 필요 영역 또는 `휴가·연차`에서 요청을 선택한다.
2. 직원, 기간, 휴가 종류, 사유, 잔여 연차를 확인한다.
3. 승인 또는 반려한다.
4. 결과 모달을 닫은 후에도 휴가 관리 화면을 유지하는지 확인한다.

**성공 기준:** 승인 상태, 직원 잔여 연차, 스케줄 휴가 표시가 일관되게 갱신된다.

## SC-10 급여 예상액 확인

1. 관리자가 `급여 관리`에 들어간다.
2. 직원별 급여 형태와 이번 달 실제 근무시간을 확인한다.
3. 예상 금액과 전체 예상 인건비를 확인한다.
4. 직원 행을 눌러 급여 단가와 근태 이력을 대조한다.
5. 필요 시 CSV를 내려받아 월말 정산 자료를 확인한다.

| 급여 유형 | 현재 MVP 산정 |
| --- | --- |
| 시급제 | `시급 × 실제 퇴근 완료 근무시간` |
| 월급제 | 등록 월급 |
| 일급제 | 급여 형태 선택·저장은 가능하나, `일급 × 실제 근무일` 전용 계산은 구현 전 |

**유의:** 세금, 4대보험, 퇴직금, 주휴·연장·야간·휴일 수당은 현재 자동 정산 대상이 아니다.

## SC-11 화면 전환·탭 복귀 안정성

1. 관리자가 홈에서 스케줄·출퇴근·휴가·직원 관리·운영 설정을 차례로 이동한다.
2. 각 화면에서 5초 이상 대기한 후 홈으로 복귀한다.
3. Chrome의 다른 외부 탭을 35초 이상 사용한 뒤 TimeFit 탭으로 돌아온다.

**성공 기준:**

- 현재 화면이 불필요하게 홈으로 이동하지 않는다.
- 마지막 정상 데이터가 유지된다.
- `계정 정보를 불러오는 중`, `업무 데이터를 불러오는 중` 화면에 고정되지 않는다.
- 다른 사업장의 직원·스케줄·휴가 데이터가 노출되지 않는다.

## SC-12 예외 응답

| 상황 | 사용자 안내 및 결과 |
| --- | --- |
| 잘못된 전화번호 | 직원 정보를 찾을 수 없음 안내 후 재입력 |
| 출근 전 퇴근 시도 | 먼저 출근해야 함 안내 |
| 이미 출근한 직원의 출근 시도 | 퇴근 가능 상태 안내 |
| 태블릿 연결 만료 | 관리자 연결 화면으로 이동 |
| 휴가 계산 제외일 선택 | 운영 기준에 맞는 신청 제한 또는 차감 안내 |
| 저장·수정 실패 | 성공 문구가 아닌 원인 중심 오류 모달과 현재 화면 유지 |

## 최종 출시 합격 기준

- 관리자 가입, 사업장 생성, 로그인, 로그아웃이 정상이다.
- 직원 등록·초대 연동·개인정보 수정·연차 부여가 정상이다.
- 스케줄 일괄 등록·수정·삭제·월간 보기가 정상이다.
- 태블릿 연결, 출근, 퇴근, 휴가 신청이 관리자 웹에 반영된다.
- 휴가 승인·반려와 연차 잔여 계산이 정상이다.
- 시급·월급 예상액이 실제 근태에 따라 표시된다.
- 화면 전환 및 외부 Chrome 탭 복귀 후에도 데이터와 현재 업무 화면이 유지된다.
