# 프로덕션 총 기능·UI/UX 검토 결과

- 실행일: 2026-08-11
- 환경: 인앱 브라우저, Vercel Production
- 계정: E2E 관리자 / E2E 직원

## 통과

- 관리자 로그인, 직원 관리, 직원 상세 진입
- 관리자 운영 설정 및 태블릿 설정 UI
- 태블릿 출퇴근/휴가 신청 탭과 입력 폼
- 직원 개인 스케줄·휴가 화면
- 관리자 휴가 검토 화면
- 화면 전환 중 콘솔 오류 0건

## 발견된 차단 이슈

### P0. 직원 전화번호 저장 실패

관리자 → 직원 상세 → `전화번호 등록`에서 유효한 11자리 번호를 입력하고 저장했으나, 화면에 `전화번호를 저장하지 못했습니다.` 오류가 표시됐다. 모달도 닫히지 않았다.

영향: 태블릿 출퇴근의 뒷 4자리, 태블릿 휴가 신청의 뒷 8자리 인증을 실제로 진행할 수 없다.

필요 조치: `timefit_user_set_staff_phone` RPC의 권한/입력 검증/배포 상태를 점검하고, 서버 오류를 관리자 UI에 정확히 노출한 뒤 전화번호 저장 성공·새로고침 유지 테스트를 통과시킨다.

## UI/UX 개선 권고

- 직원 상세에 현재 등록된 전화번호를 마스킹해 보여 주고, `등록`/`수정` 상태를 구분한다.
- 전화번호 입력 시 숫자 자동 포맷과 010 기준 유효성 안내를 제공한다.
- 태블릿 휴가 신청은 PIN을 매번 입력하지 않도록 세션 시간(예: 5분)을 설정하는 방안을 검토한다.
- 관리자 대시보드의 일부 카드·승인 항목은 샘플 숫자/데이터가 남아 있어 실제 Supabase 집계로 교체해야 한다.
