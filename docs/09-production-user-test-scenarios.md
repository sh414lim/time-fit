# TimeFit 실제 사용자 기반 테스트 시나리오

> 기준 버전: 로그인 우선 진입 · 역할 기반 관리자/직원 분리 · Supabase Auth 적용본  
> 목적: 실제 사업장 운영 흐름에서 회원가입부터 초대, 근태·스케줄·휴가 관리까지 점검한다.

## 1. 테스트 역할과 사전 조건

| 역할 | 테스트 계정 조건 | 주요 목적 |
|---|---|---|
| 관리자 | 관리자 역할로 가입, 사업장명 입력 | 사업장 생성, 직원 초대, 운영 화면 확인 |
| 직원 | 직원 역할로 가입 | 고유번호 확인, 초대 수락, 개인 화면 확인 |

- 비로그인 사용자의 첫 화면은 로그인 페이지여야 한다.
- 관리자와 직원은 서로 다른 이메일 계정을 사용한다.
- 실제 QR 스캔은 HTTPS 환경, 카메라 권한, 유효한 매장 QR이 필요하다.

## 2. 전체 사용자 여정

```text
로그인 페이지
  ├─ 관리자 회원가입 → 사업장 자동 생성 → 관리자 대시보드
  │    └─ 직원 고유번호 입력 → 초대 발송
  └─ 직원 회원가입 → 고유번호 확인 → 로그인
       └─ 초대 수락 → 직원 홈 → 스케줄/출퇴근/휴가
```

## 3. 인증·사업장 온보딩

### A-01. 비로그인 첫 화면

1. 새 브라우저 세션 또는 로그아웃 상태로 TimeFit에 접속한다.
2. 첫 화면을 확인한다.

**기대 결과**

- `로그인`과 `회원가입`만 노출된다.
- 관리자/직원 모드 전환 탭과 데모 진입 버튼은 노출되지 않는다.
- 로그인 전 근태·직원·급여 데이터는 보이지 않는다.

### A-02. 관리자 회원가입과 사업장 생성

1. `회원가입`을 누르고 `관리자`를 선택한다.
2. 이름, 사업장 이름, 이메일, 8자 이상 비밀번호를 입력한다.
3. `회원가입`을 누른다.

**기대 결과**

- 이메일 인증 대기 없이 즉시 로그인된다.
- `timefit_user_accounts`에 관리자 역할 계정이 생성된다.
- `timefit_user_organizations`와 `timefit_user_memberships`에 사업장·관리자 멤버십이 생성된다.
- 관리자 대시보드와 입력한 사업장명이 보인다.

### A-03. 로그아웃과 재로그인

1. 헤더 프로필 버튼을 눌러 로그아웃한다.
2. 같은 관리자 이메일과 비밀번호로 로그인한다.

**기대 결과**

- 로그인 페이지로 이동한 뒤 다시 관리자 대시보드에 진입한다.
- 기존 사업장명이 유지된다.
- 직원 화면으로 수동 전환할 수 없다.

## 4. 직원 초대와 역할 연결

### I-01. 직원 회원가입과 고유번호 확인

1. 직원용 새 계정으로 회원가입하고 `직원`을 선택한다.
2. 이름, 이메일, 비밀번호를 입력해 가입한다.
3. 직원 홈의 `내 직원 고유번호` 카드를 확인한다.

**기대 결과**

- 직원 계정의 `timefit_user_accounts.role`은 `employee`다.
- 영문·숫자 고유번호가 표시된다.
- 사업장 초대 전에는 `직원 초대 대기` 상태가 표시된다.
- 관리자 기능과 다른 직원·급여 정보는 노출되지 않는다.

### I-02. 관리자 초대 발송

1. 관리자로 로그인한다.
2. `직원 관리` → `직원 초대`를 누른다.
3. 직원 고유번호, 부서, 직책을 입력하고 `초대 발송`을 누른다.

**기대 결과**

- 성공 안내가 표시된다.
- `timefit_user_invitations`에 `pending` 초대가 생성된다.
- 존재하지 않는 고유번호는 오류 안내를 표시한다.
- 이미 사업장에 연결된 직원은 중복 초대되지 않는다.

### I-03. 직원 초대 수락

1. 직원 계정으로 로그인한다.
2. 사업장 초대 카드를 확인한다.
3. `초대 수락하기`를 누른다.

**기대 결과**

- 직원의 사업장명이 `직원 초대 대기`에서 실제 사업장명으로 변경된다.
- 초대 상태가 `accepted`로 바뀐다.
- `timefit_user_memberships`에 직원 멤버십이 생성된다.
- 로그아웃 후 재로그인해도 연결 상태가 유지된다.

## 5. 관리자 운영 시나리오

### M-01. 출퇴근 이슈 확인

1. 관리자 홈에서 `전체 보기` 또는 `출퇴근`으로 이동한다.
2. `근무 중`, `지각`, `미출근`, `휴가` 필터를 차례로 확인한다.
3. 직원 행을 눌러 상세 화면으로 이동한다.

**기대 결과**

- 필터에 따라 직원 목록이 바뀐다.
- 행 전체를 눌러 직원 상세로 이동한다.
- 상세에서 오늘 상태, 근무시간, 연차, 최근 기록을 확인할 수 있다.

### M-02. 스케줄 확인과 근무 추가

1. `스케줄` 화면에서 날짜별 근무·휴무·연차 수를 확인한다.
2. 일간, 주간, 월간 보기를 전환한다.
3. `근무 추가`에서 직원, 날짜, 시작·종료 시각, 근무 이름을 입력해 저장한다.

**기대 결과**

- 선택 날짜에 맞춰 근무 목록과 요약이 바뀐다.
- 일/주/월 보기가 정상 전환된다.
- 저장한 일정이 현재 브라우저 테스트 상태에 즉시 반영된다.

### M-03. 휴가 요청 검토

1. `휴가 · 연차 관리`에서 승인 대기 요청을 연다.
2. 승인 또는 반려를 선택한다.
3. 목록 상태를 다시 확인한다.

**기대 결과**

- 요청 상태가 `승인 완료` 또는 `반려`로 표시된다.
- 직원 상세와 휴가 목록에서 같은 상태를 확인할 수 있다.

### M-04. 급여 화면과 다운로드

1. `급여 관리`로 이동한다.
2. 직원 행을 눌러 상세로 이동한다.
3. `CSV 다운로드`를 선택한다.

**기대 결과**

- 직원별 예상 급여와 근태 확인 필요 상태가 표시된다.
- CSV 파일 다운로드가 시작된다.

## 6. 직원 업무 시나리오

### E-01. 내 스케줄 확인

1. 직원 홈에서 `내 스케줄`로 이동한다.
2. 월간 캘린더와 등록 근무 목록을 확인한다.

**기대 결과**

- 개인 근무·휴무 일정만 보인다.
- 다른 직원의 급여·근태·연차 정보는 보이지 않는다.

### E-02. QR 출퇴근

1. `출퇴근`으로 이동한다.
2. `QR 출근`을 누르고 카메라 권한을 허용한다.
3. 당일 유효한 매장 QR을 스캔한다.
4. 같은 QR로 `QR 퇴근`을 진행한다.

**기대 결과**

- 출근 성공 후 버튼이 퇴근 상태로 바뀐다.
- 중복 출근, 만료 QR, 다른 사업장 QR은 실패 안내를 보여 준다.
- 성공 기록은 출퇴근 이력과 관리자 출퇴근 화면에 반영된다.

### E-03. 휴가 신청

1. `휴가` → `휴가 신청`을 누른다.
2. 유형, 시작·종료일, 사유를 입력해 신청한다.
3. 내 휴가 내역에서 상태를 확인한다.

**기대 결과**

- 새 요청이 `승인 대기`로 표시된다.
- 관리자가 처리한 뒤 직원 화면의 상태가 일치한다.

## 7. 모바일 회귀 테스트

| 항목 | 확인 방법 | 기대 결과 |
|---|---|---|
| 로그인 화면 | 390px 너비에서 접속 | 입력 필드·가입 전환 버튼이 잘리지 않음 |
| 직원 하단 메뉴 | 내 홈, 스케줄, 출퇴근, 휴가 이동 | 4개 메뉴가 모두 터치 가능 |
| 관리자 더보기 | 홈/출퇴근/스케줄/더보기에서 진입 | 휴가·급여·직원 관리 항목이 스크롤 가능 |
| 스케줄 | 일/주/월 전환과 날짜 선택 | 날짜·요약·근무 카드가 겹치지 않음 |
| 바텀시트 | 초대·휴가·근무 추가 폼 | 닫기와 저장 버튼이 하단 메뉴에 가려지지 않음 |

### 현재 구현 유의사항

- 인증·역할·사업장·초대 데이터는 Supabase에 영속된다.
- QR 출퇴근은 Supabase Edge Function과 DB 기록 흐름을 사용한다.
- 스케줄 추가, 휴가 신청·승인, 급여 예상액은 현재 MVP 테스트 상태 중심 화면이므로, 정식 출시 전에는 각 업무 데이터의 Supabase CRUD·실시간 반영을 별도 종단 간 검증한다.
