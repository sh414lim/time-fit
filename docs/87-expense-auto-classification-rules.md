# 가맹점 자동 분류 규칙 구현

관리자가 영수증 OCR 값을 수정할 때 `같은 가맹점은 다음부터 자동 적용`을 선택하면 분류와 기본 지출 사유를 규칙으로 저장한다.

## 규칙 우선순위

1. 사업자등록번호 정확히 일치
2. 정규화된 상호 정확히 일치
3. LLM이 제안한 분류
4. 분류 미지정 상태로 관리자 검토

사업자번호는 상호 변경이나 지점 표기 차이에도 안정적이므로 상호 규칙보다 항상 우선한다.

## 자동 적용 결과

- 이후 같은 가맹점 영수증의 계정 분류 자동 입력
- 저장된 기본 지출 사유 자동 입력
- 적용 규칙 ID를 지출에 기록
- 규칙별 적용 횟수와 최근 적용 시각 기록
- 관리자는 카드 후보만 확인하고 확정 가능

카드 후보가 없는 현금 영수증도 OCR 지출 초안을 수정하고 규칙을 학습시킬 수 있도록 검토 API가 문서와 지출을 직접 연결해 반환한다.
