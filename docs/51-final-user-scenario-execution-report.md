## 관찰된 범위

- 프로덕션 관리자 화면은 실제 사업장 데이터를 정상 유지했다.
- 화면을 이동해도 계정 정보를 다시 불러오는 고정 화면으로 전환되지 않았다.
- 급여 관리 화면은 진입 가능하며, 현재 MVP에서 시급·월급 예상값 표시 범위를 확인했다.
- 일급제 전용 단가 입력 및 `일급 × 실제 근무일` 계산은 아직 구현 전이므로 급여 정산 최종 통과 대상에서는 제외한다.
