# TimeFit - 급여·세무·스케줄 확장 요구사항

> 상태: 요구사항 검토 완료 / 개발 범위 확정 필요
> 
> 목적: 근태 관리 MVP를 급여 정산, 세무사 협업, 직원 알림까지 확장한다.

---

## 핵심 방향

- TimeFit은 근태 원천 데이터(스케줄·출퇴근·휴가)를 신뢰성 있게 관리한다.
- 급여·세금·4대보험·퇴직금은 자동 계산 초안을 만들고, 관리자 또는 세무·노무 담당자가 최종 승인한다.
- 세무 신고 자체를 즉시 자동화하지 않고, 초기에는 정산 파일 생성과 세무사 전달 업무를 자동화한다.

---

## 요구사항 목록

### 1. 급여 및 스케줄 정리

**목표**

- 직원별 스케줄, 실제 출퇴근, 휴가·휴무를 급여 산정의 기준 데이터로 통합한다.

**필요 기능**

- [ ] 시급제·일급제·월급제별 예상 급여 계산
- [ ] 스케줄 기준 근무시간과 실제 출퇴근 기준 근무시간 비교
- [ ] 휴게시간, 지각, 조기퇴근, 결근, 휴일근무 기록
- [ ] 직원별 급여 항목과 산정 근거 조회
- [ ] 월별 급여 초안·검토·확정·재마감 상태 관리

**관리자 화면**

- 급여 관리: 직원별 기본급, 수당, 공제, 예상 실수령액, 마감 상태
- 직원 상세: 기간별 근무시간·휴가·급여 산정 근거
- 월별 정산: 사업장 인건비 합계, 직원 수, 예외 내역, 파일 내보내기

**결정 필요**

- 급여 기준일·지급일·주급/월급 여부
- 연장·야간·휴일근로 수당 규칙
- 결근·지각·조기퇴근 공제 규칙

---

### 2. 월말 정산 및 세무 서류 자동 정리

**목표**

- 월 급여 마감 후 세무사에게 전달할 자료를 일관된 형식으로 자동 생성한다.

**필요 기능**

- [ ] 마감 전 근태 누락·미승인 휴가·미확정 출퇴근 검증
- [ ] 급여대장 및 근태 집계표 생성
- [ ] 직원별 지급·공제 내역 생성
- [ ] 세무사 전달용 사업장 요약표 생성
- [ ] CSV/XLSX/PDF 파일 내보내기
- [ ] 파일 생성·수정·발송 이력 보관

**권장 업무 흐름**

1. 관리자가 정산 월과 대상 직원을 확인한다.
2. 시스템이 누락·예외 데이터를 안내한다.
3. 급여 초안을 생성한다.
4. 관리자가 검토 후 급여를 확정한다.
5. 세무사 전달용 파일과 이메일 초안을 생성한다.
6. 관리자가 최종 승인 후 발송한다.

---

### 3. 퇴직금·4대보험·세금 계산

**목표**

- 법정 계산을 돕는 예상값과 산정 근거를 제공한다.

**필요 기능**

- [ ] 퇴직금 예상 계산
- [ ] 4대보험 근로자·사업주 부담 예상액
- [ ] 근로소득 원천세·지방소득세 예상액
- [ ] 입·퇴사, 휴직, 보수 변경 등 예외 입력
- [ ] 계산 규칙의 적용 시작일·종료일·버전 관리
- [ ] 세무·노무 담당자의 검토·승인 이력

**운영 원칙**

- 화면에는 항상 `예상액`으로 표시한다.
- 최종 확정은 관리자·세무사·노무사 승인 후에만 가능하다.
- 요율과 신고 기준은 코드에 고정하지 않고 정책 데이터로 관리한다.

**결정 필요**

- 근로자·일용근로자·사업소득자 분류
- 비과세 수당·상여금·식대 운영 여부
- 4대보험과 퇴직금 검토 담당자

---

### 4. 세무사 이메일 발송

**목표**

- 월 마감 자료를 세무사에게 안전하게 전달하고, 발송 이력을 남긴다.

**필요 기능**

- [ ] 사업장별 세무사 수신자·참조자 관리
- [ ] 이메일 제목·본문 템플릿
- [ ] 첨부 파일 미리보기
- [ ] 발송 전 관리자 승인
- [ ] 발송 성공·실패·재발송 이력
- [ ] 만료 링크 또는 보안 첨부 방식

**권장 상태**

`초안 → 검토 완료 → 발송 승인 → 발송 완료 / 발송 실패`

---

### 5. 카카오 알림톡

**목표**

- 직원과 관리자에게 필요한 운영 이벤트를 즉시 안내한다.

**우선 알림 이벤트**

| 이벤트 | 수신자 | 내용 |
| --- | --- | --- |
| 휴가 신청 | 관리자 | 직원명, 날짜, 휴가 유형, 관리 링크 |
| 휴가 승인·반려 | 직원 | 결과, 날짜, 관리자 메모 |
| 스케줄 변경 | 직원 | 변경 전·후 일정 |
| 급여명세 준비 | 직원 | 대상 월, 확인 링크 |
| 정산 자료 준비 | 관리자 | 대상 월, 검토 링크 |

**필요 기능**

- [ ] 템플릿 승인 상태 관리
- [ ] 발송 대기열, 성공·실패·재시도 이력
- [ ] 수신 동의·전화번호·퇴사 상태 검증
- [ ] 알림톡 실패 시 문자 대체 발송 정책

---

### 6. 스케줄표 작성 및 직관적 UI

**관리자 요구사항**

- [ ] 일간·주간·월간 보기
- [ ] 복수 직원·복수 날짜 일괄 등록
- [ ] 일정 수정·삭제 및 변경 이력
- [ ] 근무 형태별 색상
- [ ] 파트·직원·근무 형태·휴가 상태 필터
- [ ] 인원 부족, 휴가·근무 중복, 미배정 직원 경고

**직원 요구사항**

- [ ] 오늘 근무와 다음 근무를 홈 상단에 표시
- [ ] 개인 월간 스케줄 조회
- [ ] 휴가 승인 상태 조회
- [ ] 스케줄 변경 전·후 내역 확인

**UX 수용 기준**

- 모바일 화면에서 시간·근무형태·상태가 잘리지 않는다.
- 모든 직원 행은 상세 화면으로 이동한다.
- 등록·수정·삭제 모든 작업에 로딩·완료·오류 안내가 있다.
- 월간 보기에서 해당 월 모든 날짜의 근무·휴무·휴가 현황을 확인할 수 있다.

---

### 7. 직원 관리 및 파트별 분리

**목표**

- 부서·파트별 직원과 스케줄을 분리하고, 파트 관리자 권한을 제공한다.

**권한 제안**

| 역할 | 직원 정보 | 스케줄 | 급여·세무 | 운영 설정 |
| --- | --- | --- | --- | --- |
| 전체 관리자 | 전체 조회·수정 | 전체 관리 | 조회·마감·발송 | 가능 |
| 파트 관리자 | 담당 파트 | 담당 파트 | 불가 또는 요약만 | 불가 |
| 직원 | 본인만 | 본인만 조회 | 본인 명세만 | 불가 |

**필요 데이터**

- [ ] 파트: 이름, 색상, 정렬 순서, 활성 상태
- [ ] 직원-파트: 직원, 파트, 기본 파트, 적용 기간
- [ ] 스케줄-파트 또는 근무 위치 연결
- [ ] 역할: 전체 관리자, 파트 관리자, 직원

## 개발 우선순위

### P0 - 근태와 운영 기반

- 파트 관리 및 파트별 스케줄 필터
- 스케줄·출퇴근·휴가 데이터 정합성
- 근태 확정 및 수정 이력
- 급여 계약과 급여 항목 데이터 모델

### P1 - 월말 급여 정산

- 급여 초안·검토·마감
- 급여대장·근태 집계표 생성
- CSV/XLSX 내보내기
- 세무사 이메일 발송

### P2 - 세무·노무 계산 지원

- 퇴직금 예상 계산
- 4대보험·세금 예상 계산
- 규칙 버전 관리 및 검토 승인

### P3 - 운영 자동화

- 카카오 알림톡
- 회계·세무 서비스 연동
- 전자신고 연동 검토

---

## 확정이 필요한 질문

1. 급여는 실제 지급까지 관리할지, 세무사 전달용 정산 초안까지만 관리할지?
2. 세무·노무 담당자는 누구이며, 최종 승인 권한은 누구에게 둘지?
3. 급여 항목, 수당·공제 규칙, 비과세 항목은 무엇인지?
4. 세무사가 원하는 전달 파일 형식과 월 마감 일정은 무엇인지?
5. 카카오 알림톡 발송 대행사와 템플릿 승인 절차는 어떻게 할지?
6. 파트 관리자에게 공개할 직원 개인정보·급여 정보 범위는 어디까지인지?
