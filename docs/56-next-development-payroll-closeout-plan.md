# TimeFit 다음 개발 기획 — 급여 마감·월말 정산 초안

## 목표

현재의 스케줄·출퇴근·휴가·매출·증빙 업로드 데이터를 하나의 월별 **정산 초안**으로 묶는다. 관리자가 근태 누락을 검토하고 급여 초안을 확정한 뒤, 세무사에게 전달할 CSV/XLSX와 이메일 요약을 생성하는 단계다.

> 이 단계의 계산 결과는 `예상/검토용`이다. 4대보험·원천세·퇴직금의 법정 확정 계산이나 신고 제출은 세무·노무 검토 기준이 확정된 다음 단계로 분리한다.

## 사용자 흐름

1. 관리자가 `정산 · 매출 > 급여 마감`에서 대상 월을 고른다.
2. 시스템이 직원별 예정 근무, 실제 출퇴근, 승인 휴가, 휴무, 누락 근태를 집계한다.
3. 관리자가 누락·조기퇴근·수정 필요 항목을 보정하고 사유를 입력한다.
4. 시급·일급·월급 계약 기준으로 직원별 급여 초안을 생성한다.
5. 관리자가 항목별 조정값과 메모를 남기고 `검토 완료` 또는 `마감 확정`한다.
6. 확정 버전 기준으로 근태 집계표·급여대장·세무사 전달 요약을 CSV/XLSX로 다운로드한다.
7. 기존 세금계산서·매출전표와 함께 세무사 이메일 미리보기를 확인한 뒤 수동 발송한다.

## 화면 설계

### 1. 급여 마감 목록

- 월 선택, 상태: `초안 / 검토 중 / 확정 / 재마감 필요`
- 전체 인건비, 대상 직원 수, 근태 누락 수, 승인 대기 휴가 수
- `초안 생성`, `CSV/XLSX 다운로드`, `세무사 전달` 버튼

### 2. 직원별 급여 검토

- 좌측: 직원, 파트, 급여 형태, 상태, 예상 지급액
- 우측: 날짜별 예정/실제 근무시간, 휴가·휴무, 보정 이력
- 지급: 기본급, 연장·야간·휴일 수당(정책 적용 후), 수동 조정
- 공제: 1차에는 관리자 수동 입력과 메모만 제공
- 모든 수정은 작성자·수정시각·사유를 기록

### 3. 마감 및 세무사 전달

- 마감본 번호(예: `2026-08 v1`)와 확정 시각 표시
- 발송 전 미리보기: 매출 요약, 인건비, 증빙 수, 첨부/다운로드 목록
- 수신자·참조자·제목·본문 템플릿을 사업장별로 저장
- 발송 성공·실패·재발송 이력 표시

## 데이터 설계

| 테이블 | 용도 | 핵심 필드 |
| --- | --- | --- |
| `timefit_user_payroll_contracts` | 계약 단가의 기간별 이력 | staff_id, pay_type, hourly/daily/monthly_rate, effective_from/to |
| `timefit_user_payroll_closes` | 월별 마감 헤더 및 버전 | organization_id, settlement_month, version, status, closed_by/at |
| `timefit_user_payroll_lines` | 직원별 급여 초안/확정 스냅샷 | close_id, staff_id, scheduled_minutes, worked_minutes, base_pay, adjustments, deductions, net_estimated |
| `timefit_user_attendance_adjustments` | 근태 보정 이력 | attendance_id, before/after, reason, adjusted_by/at |
| `timefit_user_payroll_line_items` | 지급·공제의 세부 항목 | payroll_line_id, type, label, amount, calculation_source |
| `timefit_user_settlement_deliveries` | 세무사 이메일 이력 | 이미 구현됨: 수신자, 월, 발송 상태, 요약값 |

마감 확정 시 `payroll_lines`에 계산 결과와 적용된 정책 버전을 저장해, 이후 운영 설정이 바뀌어도 과거 급여가 달라지지 않게 한다.

## 계산 원칙

- 시급제: 실제 퇴근 완료 근무시간 × 시급. 현재 운영 설정의 30분 등 반올림 규칙을 적용.
- 일급제: 퇴근 완료 일수 × 등록 일급. 반일·휴가·휴무 처리 규칙은 명시적으로 표시.
- 월급제: 계약 월급을 기본값으로 하되 결근·무급휴가·수동 조정은 별도 항목으로 기록.
- 승인 휴가, 정기휴일·공휴일 보상은 현재 운영 정책의 결과를 참조하고, 계산 근거를 라인 항목에 남긴다.
- 연장·야간·휴일 수당은 수당률 및 기준 시간이 확정되기 전까지 자동 확정 계산하지 않는다.

## 권한과 안전장치

- 전체 관리자만 급여 초안 생성·수정·마감·세무사 발송을 수행한다.
- 파트 관리자 기능이 도입되더라도 급여 금액·세무 문서는 기본 비공개다.
- 확정된 마감월의 근태·휴가를 바꾸면 `재마감 필요` 상태로 전환한다.
- 세금계산서와 매출전표는 공개 링크가 아닌 TimeFit 권한 기반 다운로드를 유지한다.
- 직원 화면에는 본인 급여명세가 정식 제공되기 전까지 금액을 노출하지 않는다.

## 개발 순서

1. **근태 보정과 급여 계약 이력** — 계약 변경 이력, 근태 수정 사유, 누락 검증.
2. **급여 초안 엔진** — 시급·일급·월급 집계, 조정 항목, 직원별 검토 화면.
3. **마감 버전·다운로드** — 확정 스냅샷, CSV 우선 생성, XLSX 생성 추가.
4. **세무사 전달 고도화** — 발송 미리보기, CC·템플릿, 문서 목록, 재발송 이력.
5. **법정 예상 계산** — 정책 버전 테이블 기반 4대보험·원천세·퇴직금 예상액. 세무·노무 검토 후 착수.

## 다음 구현 단위 (P0)

`급여 계약 이력 + 급여 초안 생성`을 먼저 구현한다.

- 직원별 단가의 적용 시작일을 기록한다.
- 선택 월의 실제 근태와 휴가를 집계한다.
- 급여 관리 화면에서 초안 금액과 근거를 조회한다.
- 아직 확정·세금공제·직원 명세서 발송은 포함하지 않는다.

## 구현 전 확정할 운영 정보

1. 급여 마감일과 지급일, 주급/월급 여부
2. 연장·야간·휴일 수당률 및 적용 기준
3. 지각·조기퇴근·결근·무급휴가 공제 규칙
4. 식대·교통비·상여 등 지급 항목과 비과세 여부
5. 세무사 수신자·참조자, 원하는 CSV/XLSX 양식
