## 시나리오별 메모

1. 관리자 가입, 사업장 생성, 직원 고유번호 발급, 관리자 초대, 직원 수락은 기존 QA 계정으로 실제 완료된 상태를 재검증했습니다. 로그인 후 사업장 연결 상태가 유지됩니다.
2. 직원의 QR 출근은 `QR 출근` 버튼과 안내 화면까지 확인했습니다. 카메라 접근은 브라우저 권한 승인 동작이므로 실제 촬영 테스트에서는 제외했습니다.
3. 급여 화면의 CSV 다운로드는 다운로드 확인이 필요한 동작이므로 클릭하지 않았습니다. 화면 진입 및 급여 관리 UI까지만 확인했습니다.

## 출시 전 확인 필요 사항

- 스케줄, 휴가 신청/승인, 급여 데이터는 현재 MVP 화면 상태 중심으로 동작합니다. 실제 다중 사용자 운영을 위해서는 각 변경을 Supabase CRUD로 영속화하고, 다른 계정에서 즉시 반영되는지 별도 통합 테스트가 필요합니다.
- 실제 매장 QR 코드, HTTPS 카메라 권한, 모바일 실기기에서의 QR 촬영 성공/실패 케이스를 출시 전 확인해야 합니다.
- CSV 파일의 실제 생성·다운로드 결과도 운영 환경에서 한 번 검증해야 합니다.
