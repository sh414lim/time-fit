# TimeFit 신규 Supabase 사용자 시나리오

작성일: 2026-08-16  
대상 환경: 신규 Supabase `timefit` / 웹 프로덕션 / Android 태블릿

## 1. 목적

신규 DB에서 관리자 가입, 직원 계정 연결, 관리자 운영, 태블릿 출퇴근과 휴가 신청이 하나의 사업장 데이터로 이어지는지 검증한다.

## 2. 테스트 사용자

| 역할 | 사용자 | 로그인 | 태블릿 번호 |
|---|---|---|---|
| 관리자 | 테스트 관리자 | `timefit.qa.manager@example.com` | - |
| 직원 | 테스트 직원 임세환 | `timefit.qa.sehwan@example.com` | `4724` / 휴가용 `55554724` |
| 직원 | 테스트 직원 김민지 | `timefit.qa.minji@example.com` | `6789` / 휴가용 `55556789` |
| 직접 등록 직원 | 테스트 직원 이준호 | 계정 연결 전 | `1234` / 휴가용 `55551234` |

비밀번호는 테스트 공용 비밀번호를 사용하되, 운영 전에는 반드시 교체한다.

## 3. 관리자 웹 시나리오

### A. 로그인과 사업장 확인

1. 웹앱에 접속해 관리자 계정으로 로그인한다.
2. 대시보드에 `타임핏 QA 사업장`이 표시되는지 확인한다.
3. 직원 수와 직원 목록에 임세환, 김민지, 이준호가 표시되는지 확인한다.
4. 새로고침 또는 로그아웃 후 재로그인해도 다른 사업장 정보가 잔존하지 않는지 확인한다.

기대 결과: 관리자만 사업장 전체 정보·운영 메뉴에 접근하며, 새 DB의 데이터만 표시된다.

### B. 직원 상세 관리

1. 직원 목록에서 임세환을 선택한다.
2. 전화번호, 직책, 시급, 입사일, 남은 연차를 확인한다.
3. 직책 또는 시급을 수정하고 저장한다.
4. 연차를 1일 부여하고 부여 이력이 남는지 확인한다.
5. 목록으로 돌아와 요약 정보가 갱신됐는지 확인한다.

기대 결과: 직원 상세 수정과 연차 부여는 즉시 영속화되며 관리자에게만 노출된다.

### C. 일정 등록과 수정

1. 스케줄 관리에서 임세환과 김민지를 복수 선택한다.
2. 근무 날짜를 캘린더에서 복수 선택한다.
3. 근무 형태, 시작·종료 시간, 휴게시간을 입력하고 저장한다.
4. 월간 보기에서 대상 날짜 전체에 일정이 표시되는지 확인한다.
5. 일정 한 건을 수정한 뒤 저장하고, 다른 한 건을 삭제한다.

기대 결과: 선택한 직원×날짜 조합만 생성되고, 수정·삭제가 새로고침 이후에도 반영된다.

### D. 휴가 승인

1. 태블릿 또는 직원 웹에서 생성된 휴가 신청을 관리자 휴가 메뉴에서 연다.
2. 직원, 날짜, 휴가 유형, 차감 일수를 확인한다.
3. 한 건은 승인하고 다른 한 건은 반려한다.
4. 직원 상세의 연차 잔여량과 휴가 목록 상태를 확인한다.

기대 결과: 승인/반려 상태와 차감 결과가 일관되게 표시된다.

## 4. 직원 웹 시나리오

### A. 초대 수락 후 로그인

1. 임세환 또는 김민지 계정으로 로그인한다.
2. 초대가 이미 수락된 경우 본인 사업장과 개인 화면으로 바로 진입하는지 확인한다.
3. 다른 직원의 개인정보, 급여, 일정 수정 메뉴가 노출되지 않는지 확인한다.

기대 결과: 직원은 본인의 스케줄·근무시간·휴가 정보만 조회한다.

### B. 개인 일정과 휴가 상태

1. 내 스케줄에서 등록된 근무일과 시간을 확인한다.
2. 휴가 목록에서 신청 상태와 잔여 연차를 확인한다.
3. 관리자 승인/반려 후 새로고침해 상태가 갱신되는지 확인한다.

기대 결과: 권한 밖의 관리 정보는 노출되지 않고 본인 데이터만 최신 상태로 보인다.

## 5. 태블릿 시나리오

### A. 관리자 태블릿 연결

1. 초기 태블릿 화면에서 관리자 이메일·비밀번호를 입력한다.
2. `사업장 태블릿으로 연결`을 선택한다.
3. 연결 완료 모달과 사업장 전용 태블릿 화면을 확인한다.
4. 앱을 재시작해도 연결 상태가 유지되는지 확인한다.

기대 결과: 관리자 인증 성공 시 해당 사업장 토큰만 기기에 저장된다.

### B. 출근·퇴근

1. 출퇴근 탭에서 전화번호 입력 카드를 선택한다.
2. 전용 키패드로 임세환의 뒤 4자리 `4724`를 입력하고 `입력 완료`를 누른다.
3. 입력 카드에 `4724`가 즉시 반영되는지 확인한다.
4. `직원 확인`을 누르고 이름·출근 또는 퇴근 예정 액션이 맞는지 확인한다.
5. `완료`를 눌러 기록을 저장한다.
6. 관리자 웹 출퇴근 목록에서 시간·직원·태블릿 출처가 표시되는지 확인한다.
7. 같은 날 동일 액션을 한 번 더 시도해 `이미 출근 처리됨` 또는 `이미 퇴근 처리됨` 안내가 표시되는지 확인한다.

기대 결과: 조회와 저장이 같은 다음 액션을 반환하며, 중복 기록은 생성되지 않는다.

### C. 휴가 신청

1. 휴가 신청 탭으로 전환한다.
2. 휴가용 뒤 8자리 `55554724`를 키패드로 입력한다.
3. 날짜 카드에서 미래 날짜를 캘린더로 선택한다.
4. 연차, 오전 반차, 오후 반차 중 한 유형을 선택한다.
5. `직원 확인`을 눌러 본인 확인 모달을 확인한다.
6. `완료`로 휴가 신청을 제출한다.
7. 관리자 웹 휴가 신청 목록에서 신규 신청이 보이는지 확인한다.

기대 결과: 휴가 신청은 한 건만 생성되고, 공휴일·휴일 정책에 따라 차감 불가 안내 또는 정상 신청 결과를 반환한다.

### D. 태블릿 오류 안내

1. 등록되지 않은 번호를 입력한다.
2. 만료된 태블릿 연결 또는 비활성화된 태블릿 환경에서 조회한다.
3. 이미 출근한 직원으로 출근 저장을 재시도한다.
4. 출근 없이 퇴근을 시도한다.

기대 결과: 일반 실패 문구가 아니라 직원 없음, 연결 만료, 이미 출근, 출근 기록 없음 등 원인별 안내 모달이 표시된다.

## 6. 최종 통과 기준

- 관리자·직원·태블릿에서 동일 사업장 데이터가 즉시 일치한다.
- 일정, 출퇴근, 휴가 신청/승인 결과가 새로고침 후에도 유지된다.
- 역할 밖의 메뉴·개인정보는 노출되지 않는다.
- 태블릿 입력값은 출퇴근과 휴가 간 서로 섞이지 않는다.
- 오류는 사용자가 다음 행동을 알 수 있는 안내 문구로 표시된다.
