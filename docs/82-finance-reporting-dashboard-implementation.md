# 일·주·월·연간 운영손익 및 결산 구현

## 집계 기준

- 순매출: Toss Place 일별 완료 매출
- 운영지출: `confirmed` 상태 지출만 합산
- 인건비: 저장된 월 급여 초안 합계를 달력 일수로 일할 배분
- 운영순익: 순매출 - 운영지출 - 인건비

일간·주간·월간·연간 화면과 결산 스냅샷 API가 동일한 집계 함수를 사용하므로 화면 숫자와 저장된 결산 숫자가 달라지지 않는다.

## 화면 기능

- 일간·주간·월간·연간 전환
- 기준일 선택과 실제 집계 범위 표시
- 순매출·확정 지출·인건비·운영순익 카드
- 일별 운영순익 추이 차트
- 결산 스냅샷 버전 저장
- 급여 초안 누락 월 경고
- 미처리 영수증 건수 경고

## 결산 완성도 제어

급여 초안이 누락됐거나 선택 기간에 OCR 처리·검토가 끝나지 않은 영수증이 있으면 결산을 `ready`가 아닌 `draft`로 저장한다. 운영자가 누락을 모른 채 결산을 확정하는 상황을 방지한다.

결산 저장은 사업장 소유자만 가능하며 일반 관리자는 보고서 조회만 할 수 있다.

## 현재 인건비 해석

일·주간 인건비는 저장된 월 급여 초안을 달력 일수로 배분한 발생주의 추정치다. 직원별 실제 일간 인건비 정밀 계산은 일별 근태·급여 원장을 추가하는 후속 단계에서 대체해야 한다.

## 검증

- 계산 단위 테스트에서 매출 800,000원, 지출 100,000원, 일할 인건비 200,000원의 운영순익이 500,000원인지 확인했다.
- 전체 Node 테스트와 프로덕션 빌드를 통과해야 배포 대상으로 인정한다.
