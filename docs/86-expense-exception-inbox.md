# 지출 예외 통합 업무함 구현

정상 건을 관리자 화면에서 제외하고 실제 조치가 필요한 항목만 통합한다.

## 포함 항목

- 영수증이 연결되지 않은 카드 거래
- OCR 처리 실패
- 영수증 검토 대기
- 카드 자동수집 장애와 재인증
- 초안 또는 재오픈 상태 결산

## 우선순위

- 미증빙 카드 거래 7일 이상: 긴급
- 미증빙 카드 거래 3일 이상: 주의
- OCR 실패: 긴급
- 영수증 검토 3일 이상: 긴급
- 카드 재인증: 긴급
- 일반 카드 동기화 장애: 주의

심각도가 같으면 오래된 항목을 먼저 표시한다. 항목별 담당자와 경과일을 보여주며 `처리 위치로 이동` 버튼으로 카드·영수증·결산 영역에 바로 이동한다.

## 관리자 절감 효과

- 여러 화면을 돌아다니며 실패 건을 찾을 필요가 없다.
- 정상 자동 매칭 건은 업무함에 나타나지 않는다.
- 긴급·주의·유형 필터로 오늘 처리할 업무를 빠르게 구분한다.
- 새로고침 한 번으로 카드·OCR·결산 예외 상태를 다시 집계한다.
