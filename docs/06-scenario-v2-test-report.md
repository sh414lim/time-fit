## 세부 검증

### 관리자 모바일 더보기

- 하단에는 `홈 / 출퇴근 / 스케줄 / 더보기` 4개만 표시됐다.
- 더보기를 열면 `휴가 · 연차`, `급여 관리`, `직원 관리`가 큰 터치 행으로 표시됐다.
- 이전 6개 하단 탭 구성에서 발생할 수 있던 좁은 탭 폭 문제가 해소됐다.

### 날짜별 동적 스케줄

8월 9일에서 `월 10`을 선택한 결과:

- 헤더가 `8월 10일 월요일`로 변경됐다.
- 선택 날짜 버튼이 활성 상태로 바뀌었다.
- 집계가 `근무 2명 / 휴무 0명 / 연차 1명`으로 변경됐다.
- 근무 목록이 김민지·박서연·한유진의 8월 10일 데이터로 바뀌었다.

이는 2차 수용 기준의 “날짜 선택이 근무·휴무·연차 수와 직원 행을 갱신한다”를 충족한다.

### 직원 모드

- `내 스케줄` 화면이 정상적으로 열렸다.
- `휴가 신청` 버튼을 눌렀을 때 휴가 유형, 시작일, 종료일, 사유를 가진 바텀시트가 열렸다.
- `출퇴근` 화면에서 `QR 출근` 버튼이 정상 노출됐다.

## 결론

현재 배포 UI는 2차 시나리오의 모바일 탐색, 날짜별 스케줄 조회, 직원 상세 접근, 개인 휴가·출퇴근 진입 기준을 충족한다. 다음 개발 우선순위는 UI 확장보다 API·PostgreSQL 영속화와 QR 실기기 검증이다.
