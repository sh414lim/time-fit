# E2E QA 계정 시나리오 테스트 결과

- 실행일: 2026-08-11
- 환경: Vercel Production, 인앱 브라우저
- 사업장: E2E 테스트 사업장
- 계정: E2E 관리자, E2E 직원

| 영역 | 결과 | 근거 |
| --- | --- | --- |
| QA 관리자·직원 가입/초대/수락 | 통과 | 관리자 사업장 생성, 직원 고유번호 발급, 초대·수락 후 사업장 연결 확인 |
| 직원 역할 화면 | 통과 | 내 스케줄·휴가 화면 확인, 관리자 전용 설정 미노출 |
| 관리자 운영 설정 | 통과 | 태블릿 PIN·활성화 설정 화면 및 저장 UI 확인 |
| 관리자 휴가 검토 화면 | 통과 | 휴가 관리 및 요청 검토 CTA 확인 |
| 태블릿 출퇴근/휴가 신청 UI | 통과 | 출퇴근/휴가 탭, 전화번호 뒷 8자리, 날짜, 연차·반차 선택 UI 확인 |
| 콘솔 오류 | 통과 | 테스트 중 console error 0건 |
| 실제 태블릿 출퇴근 저장 | 보류 | 직원 전화번호 뒷 4자리 등록 UI 없음 |
| 실제 태블릿 휴가 신청·관리자 승인 | 보류 | 직원 전화번호 뒷 8자리 등록 UI 없음 |
| 카카오 알림톡 수신 | 보류 | 딜러사 API 키·발신 프로필·승인 템플릿 미등록 |

## 결론

회원가입, 역할 분리, 사업장 초대, 관리자 설정, 태블릿 UI까지는 정상 동작한다. 실제 근태·휴가 데이터 저장과 관리자 승인 E2E를 완료하려면 다음 구현이 선행되어야 한다.

1. 관리자 직원 상세에서 전화번호 뒷 4자리·8자리를 등록·수정하는 UI
2. 태블릿 저장 후 관리자 화면의 실시간/새로고침 반영 검증
3. 카카오 알림톡 공급사 연동 및 발송 상태 전환 검증
