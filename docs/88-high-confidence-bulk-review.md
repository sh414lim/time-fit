# 고신뢰 영수증 일괄 확정 구현

## 적용 조건

- 매칭 점수 95점 이상
- 영수증별 최상위 카드 후보
- 아직 확정 또는 반려되지 않은 후보
- 지출·카드 거래·문서 연결값이 모두 존재

화면 조건뿐 아니라 서버가 같은 영수증의 모든 후보를 다시 조회해 최상위 여부를 검증한다. 요청을 조작해 낮은 점수나 차순위 후보를 보내도 일괄 확정 대상에서 제외된다.

## 관리자 흐름

1. 95점 이상 후보 전체 또는 필요한 항목만 선택
2. 확정 건수 확인
3. 한 번의 확인 후 최대 50건 일괄 처리
4. 성공 건은 목록에서 제거
5. 충돌·실패 건은 목록에 유지

각 항목의 확정은 기존 원자적 매칭 RPC를 사용하므로 한 카드 거래가 여러 지출에 연결되지 않는다. 일부 항목에 충돌이 발생해도 나머지 정상 항목은 계속 처리하고 성공·실패 건수를 반환한다.
