## 확인된 동작

- 직원 권한 UI에서는 관리자 메뉴가 노출되지 않았다.
- 태블릿 출퇴근은 사업장 PIN과 직원 전화번호 뒷 4자리가 동시에 맞을 때만 직원 확인이 가능했다.
- 태블릿 휴가 신청은 직원 전화번호 뒷 8자리로 요청을 저장했고, 관리자 수신 번호가 등록된 상태에서 알림 대기열 안내가 표시됐다.
- 관리자가 휴가를 승인하면 화면 새로고침 없이 대기 건수와 요청 상태가 갱신됐다.
- 직원 휴가 화면의 데모 이름 필터를 제거하고, 로그인한 직원의 RLS 범위 내 휴가만 표시하도록 수정·배포했다.
- 직원의 직원정보·스케줄·근태·운영 설정 조회를 본인 행으로 제한하고, 관리자는 사업장 전체를 유지하도록 RLS를 강화했다.
- 별도 관리자 B 사업장을 생성해 A 사업장의 직원·승인 요청이 표시되지 않음을 브라우저에서 확인했다.
- 동일 사업장에 두 번째 직원 A2를 초대·수락한 뒤, A1의 휴가 요청과 관리자 메뉴가 보이지 않음을 확인했다.

## 출시 판정

핵심 관리자·출퇴근 인증·휴가 신청·승인 흐름은 통과했다. 다만 다중 사업장 격리, 두 번째 직원의 개인정보 분리, 실제 카카오 알림톡 발송은 출시 전 차단 항목으로 남아 있어, MVP 공개 범위 확대 전 추가 테스트가 필요하다.
