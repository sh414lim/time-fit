## 반영한 보완 사항

1. 직원 휴가 화면을 데모 사용자 이름이 아닌 로그인한 직원의 RLS 범위 데이터로 변경했다.
2. 직원의 `staff`, `schedule`, `attendance` 조회를 본인 행으로 제한하고 관리자는 사업장 전체를 조회하도록 RLS를 강화했다.
3. 직원이 사업장 운영 설정과 태블릿 PIN을 직접 읽지 못하도록 설정 조회 권한을 관리자 전용으로 변경했다.
4. 대시보드 승인 요청을 공통 데모 데이터에서 현재 사업장의 실제 승인 대기 휴가 데이터로 변경했다.
5. 태블릿 출퇴근·휴가 신청을 서비스 역할 키 의존 없이 DB 보안 RPC로 처리하도록 변경했다.

## 결론

카카오 알림톡 실제 발송을 제외한 MVP 핵심 기능은 프로덕션 브라우저 교차 테스트를 통과했다. 관리자·직원 권한, 사업장 A/B 격리, 같은 사업장 직원 A1/A2의 휴가 정보 분리, 태블릿 출퇴근 및 휴가 신청·관리자 승인 흐름이 모두 확인됐다.
