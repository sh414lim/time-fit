# TimeFit 수정 반영 회귀 테스트 시나리오

대상: `https://timefit-omega.vercel.app/`  
목적: 실제 Supabase 데이터 노출 및 JWT 세션 갱신 보완 후 출시 전 재검증

## 1. 공통 기준

- 테스트 직원: `API 재검증 직원` 또는 실행 시 새로 만든 직접 등록 직원
- 태블릿은 해당 사업장 ID가 포함된 URL을 사용한다.
- 각 CRUD 완료 후 관리자 화면을 **새로고침**해 데이터 영속성과 최신 반영을 확인한다.
- 콘솔 오류, 샘플 수치, 타 사업장 데이터 노출은 FAIL로 기록한다.

## 2. 관리자 로그인·새로고침

### R-01. 관리자 로그인과 세션 복원

1. 관리자 계정으로 로그인한다.
2. 관리자 홈에서 사업장명·관리자 메뉴를 확인한다.
3. 페이지를 새로고침한다.
4. 로그인 상태와 같은 사업장 컨텍스트가 유지되는지 확인한다.
5. 콘솔에서 `InvalidJWTToken`, `exp` 관련 오류가 없는지 확인한다.

기대 결과: 만료 임박 토큰은 자동 갱신되며, 새로고침 후 로그인 화면으로 튕기거나 JWT 오류가 발생하지 않는다.

## 3. 실제 데이터 등록과 관리자 노출

### R-02. 직접 직원 등록

1. 관리자 홈에서 `직원 등록하기`를 누른다.
2. 이름, 전화번호, 부서, 직책, 급여 형태, 시급/월급, 입사일을 입력해 저장한다.
3. 직원 관리 목록에서 검색한다.
4. 페이지를 새로고침하고 다시 검색한다.

기대 결과: 직원의 이름·부서·직책·급여 형태·재직 상태가 입력값과 일치하고 유지된다.

### R-03. 직원 상세 실제 데이터

1. R-02 직원의 `상세`를 연다.
2. 입사일, 등록 급여, 오늘 상태를 확인한다.
3. 최근 출퇴근 기록과 이번 달 근무시간을 확인한다.

기대 결과:

- 입사일·급여는 직원 등록값과 일치한다.
- 근무시간·최근 출퇴근은 Supabase 기록 기준으로 표시된다.
- `142시간`, 고정된 과거 날짜, 고정 급여 등 샘플 수치는 표시되지 않는다.

### R-04. 관리자 홈 실제 집계

1. 출퇴근·휴가 데이터를 하나 이상 만든 뒤 관리자 홈으로 이동한다.
2. 오늘 출근, 현재 근무 중, 확인 필요, 이번 달 인건비를 확인한다.
3. 새로고침 후 동일 값을 확인한다.

기대 결과: 전체 직원 수, 실제 근무 중 인원, 승인 대기/미출근 건수, 등록 급여·실근무 기반 인건비가 표시된다. 고정값 `18명`, `23명`, `₩24.8M`은 표시되지 않는다.

### R-05. 급여 관리 실제 집계

1. 관리자 `급여 관리`를 연다.
2. 직원별 급여 형태, 실제 근무시간, 예상 급여를 확인한다.
3. CSV 다운로드를 실행한다.

기대 결과: CSV와 화면 모두 실제 직원 이름·급여 형태·실근무시간·예상 급여를 사용한다. 급여 정책 미확정 범위는 `예상`으로 표시된다.

## 4. 태블릿 출퇴근·휴가

### R-06. 숫자 키패드 입력

1. 태블릿 출퇴근 화면에서 PIN 필드를 누른다.
2. 자체 숫자 키패드로 PIN 4자리를 입력·삭제·완료한다.
3. 전화번호 끝 4자리도 동일하게 입력한다.

기대 결과: 기본 기기 키보드는 열리지 않고, 화면 내 키패드 모달로만 숫자를 입력한다.

### R-07. 신규 직원 출근·퇴근

1. R-02 직원의 PIN과 전화번호 끝 4자리로 직원 확인을 한다.
2. `출근하기`를 누른다.
3. 관리자 출퇴근 화면을 새로고침한다.
4. 같은 직원 확인 후 `퇴근하기`를 누른다.

기대 결과: 직원 실명, 출근/퇴근 상태와 시각이 관리자 화면 및 직원 상세에 일치한다. 이미 출근/퇴근한 경우에는 상태별 안내가 표시된다.

### R-08. 태블릿 휴가 신청·관리자 승인

1. 태블릿 휴가 신청에서 PIN, 전화번호 끝 8자리, 미래 날짜, 반차 또는 연차를 입력한다.
2. 성공 안내를 확인한다.
3. 관리자 휴가·연차 화면을 새로고침한다.
4. 신규 요청의 직원명·날짜·종류·일수를 확인하고 승인한다.

기대 결과: 요청은 `pending`으로 저장되며, 승인 후 `approved` 상태와 관리자 처리 결과가 즉시 반영된다.

## 5. 권한·격리 회귀

### R-09. 직원 권한

1. 직원 계정으로 로그인한다.
2. 내 휴가·내 출퇴근·내 스케줄을 확인한다.

기대 결과: 관리자 메뉴·다른 직원의 개인정보·사업장 전체 데이터가 표시되지 않는다.

### R-10. 사업장 격리

1. 다른 사업장 관리자 계정으로 로그인한다.
2. 직원, 출퇴근, 휴가, 운영 설정을 확인한다.
3. 사업장 A 태블릿 인증 정보를 사업장 B 태블릿에 입력한다.

기대 결과: 사업장 A 데이터는 노출되지 않고, 태블릿 인증·저장도 실패한다.
